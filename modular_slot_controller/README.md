# 模块插槽控制板

模块化多槽位控制器：**4 块大板 × 4 个小板 = 16 个插槽位置**。大板负责电源分配、板号链与槽位编码，小板是槽位模块，负责测温、测液位、控负载并通过金手指 I2C 与主机通信。

本目录包含硬件设计、电路方案、固件测试工程三部分。

## 1. 系统构成

```
主机/上一级
   │
   ├── 大板 1（H1/H2 级联，板号 0）
   │     ├── CN1 → 小板（槽位 1）
   │     ├── CN2 → 小板（槽位 2）
   │     ├── CN3 → 小板（槽位 3）
   │     └── CN4 → 小板（槽位 4）
   ├── 大板 2（板号 1） … 大板 4（板号 3）
```

- **大板**：+12V/+24V 分配、3.3V LDO、板号链（R-2R）、槽位编码、H1/H2 级联
- **小板**：PY32F002AF15P6TU；从金手指读板号与槽位、测 NTC 温度、测液位、控 12V 泵/阀与 24V 负载、以 I2C 从机身份应答主机
- 小板没有本地 LDO，3.3V 来自大板金手指第 9 脚

## 3. 小板硬件要点

| 功能 | 引脚 | 说明 |
|---|---|---|
| SWDIO / SWCLK | PA13 / PA14 | 调试口，**禁止复用** |
| 复位 | PF2 | NRST，不作 GPIO |
| 调试串口 | PF1 | USART1_TX，115200，只发不收 |
| 板号 | PA5 | ADC_IN5，**必须 3.3V 参考** |
| 槽位 | PA6 / PB3 | BIT0 / BIT1，大板硬编码 |
| 液位 | PA7 | MCP6541 推挽，干高湿低（极性见 §6） |
| 三路输出 | PB1 / PB2 / PB0 | 阀 / 泵 / 24V 负载，高导通，低边 AO3400A |
| 本地 I2C2 | PA0 / PA1 | 软件 I2C，ADS1115（0x48） |
| 金手指 I2C1 | PA2 / PA3 | 硬件 I2C1 AF12，**从机** |

**编号约定**：`board_id` 与 `slot_id` 在代码里都是 **0 基**（板一=0，CN1=0），对外说"板 N / 第 N 个槽位"时都要 +1。`position = board_id*4 + slot_id + 1`（1~16）。

从机地址 = `0x20 + position - 1`（0x20~0x2F）。基址用 0x20 是因为板号方案把 0x10~0x13 留给了大板 MCU。

## 4. 关键计算

| 项 | 值 | 依据 |
|---|---|---|
| 板号分档 | 512 / 1536 / 2560 码（0.41 / 1.24 / 2.06 V） | 12 位、3.3V 参考，对应 R-2R 理想电平 0 / 0.825 / 1.65 / 2.475 V 的中点 |
| 板号采样 | 平均 8~16 次、连续 3 次同档、上电等 10~50 ms | 抗插拔抖动 |
| NTC 换算 | `R = 33000 × d / b`；`T = 1/(1/298.15 + ln(R/10000)/3950) − 273.15` | ADS1115 两次单次转换：`0x8383`（AIN0−AIN1）、`0xD383`（AIN1−GND） |
| NTC 参考点 | 38°C ↔ R≈5.751 kΩ，d/b≈0.1743 | 单点标定基准 |
| NTC 异常 | 开路 d≈满量程、b≈0；短路 d≈0、b≈3.29 V | 固件报 OPEN / SHORT |
| 液位翻转 | R7=R10=R12 分压，阈值 1.65 V，翻转点约 R_w=220 kΩ，迟滞 192~252 kΩ | 干=高、湿=低（文档定义） |

## 5. 固件（测试工程）

`测试工程/PY32_Modular_Project` 是小板的 bring-up 固件，详细说明见其 `README.md`。摘要：

- 五种测试模式（自检 / 输出 / 传感器 / 主机 / 位置），编译期 `APP_TEST_MODE` 选择（小板没有 USART_RX）
- 初始化顺序：时钟 → 输出先拉低 → 串口 → ADC → 软件 I2C → ADS1115 → 输入/液位 → 板号槽位 → 金手指从机
- 从机寄存器组：8 字节只读（position / ids / 状态 / 温度 / NTC 状态 / ADC），写 2 字节 `[寄存器号, 值]`，`0x10` 为输出掩码、`0x11` 全关
- 工具 `tools/ntc_monitor.py`：走 SWD 轮询实时显示板号/槽位/NTC/温度/液位，不占串口
- 编译必须 **-O2**（-O0 时镜像 20784 字节，超出 20 KB 上限）

## 6. 已知问题

1. **液位极性因板而异**：多块板实测同一固件下读数相反。固件用 `APP_LEVEL_DRY_IS_HIGH` 宏切换，当前按"干=高"（与比较器设计一致）。换板若干湿颠倒，只改这一行。
2. **NTC 曾出现 d≈0、b≈3.2 V 的短路读数**，而电路开路时应为 d 高、b≈0。已排除固件原因，怀疑 J5 短接或 PCB 上 AIN0/AIN1 反接；复现时先用万用表量 J5 与两点电压。
3. **槽位编码电阻 R1–R8 原理图 Value 为空**，未贴时 BIT0/BIT1 可能浮空，读数不稳。
4. **金手指 I2C 从机协议尚未与主机方最终确认**，当前是"能应答、能读寄存器组"的最小实现。
5. **旧 KiCad 工程 `modular_slot_controller` 不是当前依据**，引脚与网表以 2026-11-20 的 PDF 和 `.epro` 为准。
