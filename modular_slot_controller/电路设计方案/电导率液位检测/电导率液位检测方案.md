# 电导率液位检测方案

| 项目 | 内容 |
| --- | --- |
| 项目名称 | 模块插槽控制板 |
| 应用 | 基站侧水箱液位检测 |
| 版本 | v1.0 |
| 日期 | 2026-11-15 |
| 电极 | 2 根，单点检测 |
| 状态 | 方案确认；R_w 待实测；投板前补 VDD 去耦、修正网络名 |

## 1. 系统构成

- 基站侧水箱使用 2 根电极做单点液位检测，不用浮球开关。
- 水在两根电极之间形成电阻 R_w：干态接近开路，湿态电阻下降。
- 比较器 U3 把探头电压 V_probe 与 1.65 V 阈值比较，输出干/湿数字量给 MCU GPIO。
- 当前取值：R7=220 kΩ、R13=1 kΩ、R10=R12=100 kΩ、R15=680 kΩ、C4=C5=100 nF、U3=MCP6541T-E/OT。
- 2 根电极只能判一个液位点，做不了高低两个液位；要高低液位需 3 根电极或两组独立探头。
- 与浮球开关相比无机械运动件，成本低，但依赖水的电导率，电极会极化和腐蚀。

## 2. 检测原理

### 2.1 探头分压

电极间电阻与水的电导率 σ、电极面积 A、间距 d 有关，近似：

```
R_w = d / (σ · A)
```

R7 与 R_w 串联分压：

```
V_probe = 3.3 × R_w / (R7 + R_w)
```

| R_w | V_probe | 状态 | 说明 |
| --- | --- | --- | --- |
| 开路（干） | 3.30 V | 干 | 探头电压到 VDD |
| 10 kΩ | 0.14 V | 湿 | 自来水典型 |
| 50 kΩ | 0.61 V | 湿 | 裕量约 1.0 V |
| 100 kΩ | 1.03 V | 湿 | 裕量约 0.5 V |
| 220 kΩ | 1.65 V | 临界 | 翻转点附近 |
| 252 kΩ | 1.76 V | 干侧门限 | 迟滞上沿 |

R7 同时限流，最大约 15 µA。R_w 与水质、电极面积、间距、浸入深度有关，自来水和冷凝水可能差几个数量级。

### 2.2 阈值与翻转点

R10/R12 从同一路 3.3 V 分压：

```
V_th = 3.3 × R12 / (R10 + R12) = 1.65 V
```

R10=R12=100 kΩ，分压电流 16.5 µA。R10=R12 时，翻转点约 R_w=R7=220 kΩ；加上迟滞后，窗口约 192–252 kΩ。

探头分压和阈值分压同源 3.3 V，电源漂移时两边一起变，翻转点基本不变。

### 2.3 工作过程

1. 干态：R_w 开路，V_probe=3.3 V > 1.76 V，输出高，阈值被 R15 抬到 1.76 V。
2. 水淹到两根电极：R_w 下降，V_probe 下降；当 V_probe < 1.76 V（R_w < 252 kΩ），输出翻低，阈值降到 1.54 V。
3. 水退：R_w 上升，V_probe 上升；当 V_probe > 1.54 V（R_w > 192 kΩ），输出翻高，阈值回到 1.76 V。

输出低表示湿，输出高表示干。192–252 kΩ 是保持区，水面在这个区间波动时输出不跳。

## 3. 电路拓扑

### 3.1 信号流

```
R_w → 探头 A 分压 V_probe → R13/C4 低通 → U3 IN+ → LEVEL_OUT → MCU GPIO
```

阈值由 R10/R12 给到 IN−，R15 从输出反馈到 IN− 做迟滞。

### 3.2 分块拓扑

① 探头与分压

```
        3V3
         │
       [R7]
         │
         ●────────────── J3-1  电极A
         │
      [R13 1k]
         │
         ●──────┬────── U3 IN+
                │
             [C4 100nF]
                │
               GND

J3-2  电极B ─────────── GND
```

探头等效：

```
J3-1 电极A ●
           │
        [R_w 水]
           │
J3-2 电极B ●──── GND
```

R_w 与 R7 串联分压：干态 R_w 开路，探头 A 被 R7 拉到 3.3 V；湿态 R_w 变小，探头 A 电压下降。

② 阈值

```
        3V3
         │
       [R10]
         │
         ●──────── U3 IN−
         │
       [R12]
         │
        GND
```

③ 输出与迟滞

```
             U3 OUT
                │
                ●──────── LEVEL_OUT ── MCU GPIO
                │
             [R15 680k]
                │
             U3 IN−      迟滞反馈
```

MCP6541 是推挽输出，不需要上拉；换成开漏比较器时才加上拉电阻。

### 3.3 网络连接

| 网络 | 连接点 | 作用 |
| --- | --- | --- |
| PROBE_A | J3-1、R7 下端、R13 上端 | 探头 A，湿态被水电阻拉低 |
| CMP_IN+ | R13 下端、C4 上端、U3 pin 3 | 低通后的探头电压 |
| CMP_IN− | R10 下端、R12 上端、C5 上端、R15 右端、U3 pin 4 | 阈值节点，R15 叠加迟滞 |
| LEVEL_OUT | U3 pin 1、R15 左端、MCU GPIO | 数字输出，干高湿低 |
| 3V3 | R7 上端、R10 上端、U3 pin 5 | 3.3 V 电源 |
| GND | J3-2、C4 下端、C5 下端、R12 下端、U3 pin 2 | 地 |

### 3.4 连接要点

- 电极 A 经 R7 上拉到 3.3 V，电极 B 接地；R_w 与 R7 分压。
- R13/C4 在 U3 IN+ 侧做低通。实际截止取决于 R7∥R_w 再加 R13，约 15–150 Hz，响应时间约 1–11 ms，对液位足够。
- R10/R12 给阈值，R15 从输出反馈到 IN−，形成迟滞；R15 不直接接高阻探头节点。
- 探头接 IN+、阈值接 IN−：干态输出高，湿态输出低。要湿态为高，交换 IN+/IN−，或固件取反。
- U3 pin 5 的 100 nF VDD 去耦投板前补上。

## 4. 比较器与阈值设计

### 4.1 比较器选型

| 型号 | 输出 | 供电 | 静态电流 | 结论 |
| --- | --- | --- | --- | --- |
| **MCP6541** | 推挽 | 1.6–5.5 V | 600 nA | **推荐**：轨到轨输入，SOT-23-5，立创 C2980237，约 ¥1.9–3.1 |
| TLV3011 | 开漏 | 1.8–5.5 V | 5 µA | 带 1.242 V 基准；立创只有车规 Q1，约 ¥10–22，开漏要上拉 |
| TLV3201 | 推挽 | 2.7–5.5 V | 40 µA | 40 ns 高速，本应用速度过剩，价格也更高 |
| LM393 | 开漏 | 2–36 V | 0.8 mA | 不推荐：共模输入上限 VCC−1.5 V，3.3 V 下干态超范围 |

推荐 MCP6541T-E/OT（SOT-23-5）：轨到轨输入覆盖 0–3.3 V，推挽输出直接进 GPIO，Ib 1 pA、Vos 1.5 mV、响应 4 µs。pin 2 = VSS 接 GND，pin 5 = VDD 接 3V3；MCP6541R 的电源脚相反，换型要核对。

### 4.2 阈值与迟滞

```
V_th = 3.3 × R12 / (R10 + R12)
ΔV_hys ≈ 3.3 × (R10 ∥ R12) / (R15 + R10 ∥ R12)
```

R10=R12=100 kΩ、R15=680 kΩ：V_th=1.65 V；输出高时阈值约 1.76 V，输出低时约 1.54 V，迟滞约 0.23 V。对应 R_w 翻转窗口约 192–252 kΩ。

### 4.3 当前取值

| 位号 | 值 | 作用 |
| --- | --- | --- |
| U3 | MCP6541T-E/OT | 轨到轨比较器，推挽输出 |
| R7 | 220 kΩ 1% | 探头上拉，决定翻转点约 220 kΩ |
| R13 | 1 kΩ 1% | 输入串阻，与 C4 组成低通 |
| R10 | 100 kΩ 1% | 阈值上臂 |
| R12 | 100 kΩ 1% | 阈值下臂，V_th=1.65 V |
| R15 | 680 kΩ 1% | 迟滞反馈，约 0.23 V |
| C4 | 100 nF X7R 25 V | 探头电压低通 |
| C5 | 100 nF X7R 25 V | 阈值节点滤波 |
| C2 | 100 nF X7R 25 V | U3 VDD 去耦，投板前补 |

### 4.4 取值方法

1. 按实际电极间距、浸入深度和水质测湿态电阻 R_wet。
2. R10=R12 时，V_th=1.65 V，翻转点约 R_w=R7；R7 直接取目标翻转电阻。
3. 一般让 R7 至少为 R_wet 的 2–3 倍，湿态留足裕量。
4. R15 取 680 kΩ，迟滞约 0.23 V；要更宽取 470 kΩ，要更窄取 1 MΩ。
5. R13=1 kΩ，C4=C5=100 nF；要更快响应可把 C4 降到 10–47 nF。

### 4.5 可行性边界

| R_w | V_probe | 输出 | 判断 |
| --- | --- | --- | --- |
| 10–50 kΩ | 0.14–0.61 V | 低（湿） | 可靠，裕量 0.9 V 以上 |
| 100 kΩ | 1.03 V | 低（湿） | 可靠，裕量约 0.5 V |
| 192–252 kΩ | 1.54–1.76 V | 保持 | 迟滞区，不能判 |
| 300 kΩ | 1.90 V | 高（干） | 湿态会误判干 |
| 500 kΩ–1 MΩ | 2.29–2.71 V | 高（干） | 冷凝水可能在此，当前值不可行 |

自来水/加湿水 R_w 通常 10–50 kΩ，当前值可靠。冷凝水接近纯水，R_w 可能 500 kΩ 到几 MΩ，需要加大 R7、加大电极面积或减小间距；否则改用浮球/电容式。

## 5. 激励与电极

| 项目 | 当前 | 建议 |
| --- | --- | --- |
| 激励 | R7 直接接 3V3，连续直流 | 原型可用；量产改 GPIO 或 P-MOSFET 脉冲，测量时拉高 10–20 ms |
| 脉冲等待 | — | C4=100 nF、R7=220 kΩ 时高阻态 τ 约 11 ms，等 20–50 ms；或 C4 降到 10–47 nF |
| 电极 | 2 根，外部 | 316 不锈钢或碳，不用铜/黄铜 |
| 电流 | 最大约 15 µA | 控制在 100 µA 以内，减小电解 |
| 安装 | — | 水面只在目标液位同时淹没两根电极；避开泡沫和挂水膜 |

连续直流会慢慢电解、极化电极，读数漂移。脉冲激励或交替极性可以明显减轻。

## 6. 接口定义

| 信号 | 方向 | 说明 |
| --- | --- | --- |
| J3-1 / 电极 A | 模拟 | 经 R7 上拉，接 U3 pin 3 (IN+) |
| J3-2 / 电极 B | 模拟 | 接 GND |
| EXC | MCU 输出 | 脉冲激励控制，接 R7 上端；不用脉冲时直接接 3V3 |
| LEVEL_OUT | 比较器输出 | 接 MCU GPIO；推挽，0/3.3 V |
| 3V3 / GND | 电源 | 与 MCU 同一 3.3 V 轨 |

## 7. 运行流程

1. 上电，3.3 V 与 U3 VDD 建立。
2. 连续激励时直接读；脉冲激励时拉高 EXC，等 20–50 ms。
3. 读 LEVEL_OUT。
4. 连续 3–5 次读数一致才确认状态，避免水面波动误判。
5. 每 100 ms–1 s 重复一次。
6. 干态输出高，湿态输出低；固件按这个极性处理。

## 8. 边界与异常

| 场景 | 现象 | 处理 |
| --- | --- | --- |
| 探头开路/干态 | V_probe≈3.3 V，输出高 | 正常 |
| 探头短路 | V_probe≈0 V，输出低 | 按湿态处理；可判短路 |
| 纯水/冷凝水 | R_w 很大，湿态电压接近门限，误判干态 | 实测 R_w；加大电极面积/减小间距；或换传感器 |
| 电极极化/腐蚀 | 湿态电阻随时间漂移，电极发黑 | 脉冲或交替极性；316 不锈钢/碳 |
| 泡沫/挂水膜 | 误判湿态 | 迟滞、连续采样、调整安装 |
| 长探头线 | 拾噪、ESD | R13/C4 靠比较器；接口加 TVS；必要时屏蔽 |
| 3.3 V 波动 | 阈值和探头电压一起变 | 同源分压，比例抵消；加去耦 |
| 水温变化 | 电导率约 2%/°C 变化 | 阈值留裕量；宽温范围实测 |
| 金属水箱/接地 | 地环路、电解 | 确认探头与水箱绝缘；必要时隔离 |
| 比较器输入超范围 | 输出误翻转 | 选轨到轨输入；LM393 不适合 3.3 V |

## 10. 待确认与投板前修正

- 水箱里是自来水、加湿水还是冷凝水；实测湿态电阻 R_w。
- 电极间距、浸入深度、电极面积和材料。
- 投板前补 U3 pin 5 的 100 nF VDD 去耦。
- 网络标签 `WAYER LEVEL` 改为 `WATER_LEVEL` 或 `LEVEL_OUT`。
- 激励方式：连续直流还是脉冲；脉冲时的等待时间。
- 输出极性：干高湿低，和 MCU 固件对齐。
- 探头线长度、TVS/屏蔽、是否需要隔离。
- 2 根电极是否够用；要高低液位改 3 根电极或两组探头。
- 金属水箱且接地时，确认没有地环路。
