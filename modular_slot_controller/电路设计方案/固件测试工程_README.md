## 1. 一句话定位

小板是 16 槽系统里的槽位模块：从金手指读板号和槽位号，测 NTC 温度和液位，控制 12V 泵、12V 阀、24V 负载，并通过金手指 I2C 与主机通信。

固件测试工程的目标不是完整产品逻辑，而是按顺序验证：

1. 电源、时钟、SWD 能工作。
2. 板号、槽位号能读对。
3. ADS1115、NTC、液位能读。
4. 三路 MOSFET 输出能开关。
5. 金手指 I2C 从机、调试串口 TX 能通。

## 2. 系统架构

```
主机/上一级
   │
   ├── 大板 1（H1/H2 级联，板号 00）
   │     ├── CN1 → 小板（槽位 00）
   │     ├── CN2 → 小板（槽位 01）
   │     ├── CN3 → 小板（槽位 10）
   │     └── CN4 → 小板（槽位 11）
   ├── 大板 2（板号 01）
   ├── 大板 3（板号 10）
   └── 大板 4（板号 11）
```

- 大板负责：+12V/+24V 分配、3.3V LDO、板号链、槽位编码、H1/H2 级联。
- 小板负责：读位置、测温、测液位、控负载、与主机通信。
- 小板没有本地 LDO，3.3V 来自大板金手指第 9 脚。

### 3.2 必须注意的引脚约束

- **PA0/PA1 没有硬件 I2C 复用**，只能做软件 I2C。PA0 配 SDA、PA1 配 SCL，开漏输出，靠 R4/R5 4.7k 上拉。24MHz 下 100kHz 半周期约 5µs，用 NOP 延时或定时器。
- **PA2/PA3 是硬件 I2C1，AF12**，走金手指总线，不要和 PA0/PA1 混用。
- **PA5 必须是 ADC 输入**，板号判决用 3.3V 参考，不能用内部参考。
- **PA7 是数字输入**，MCP6541 推挽，干态高、湿态低，不需要上拉。
- **PB0/PB1/PB2 输出高导通**，低边 AO3400A，栅极 10Ω 串阻、100k 下拉。复位后默认输入，100k 下拉保证负载关断。
- **PA4、PF0 当前悬空**，不要默认配置成输出。
- **PB6/PF4-BOOT0** 只做 BOOT0，不要当 GPIO 用。原理图是经电容到 GND，JLC README 写的是直接 GND，投板/实物以网表为准。

## 5. 大板接口与位置计算

### 5.1 CN1–CN4

四个座引脚定义相同，槽位编码不同：

| CN 引脚 | 信号 | 说明 |
| --- | --- | --- |
| 1 | I2C_SCL | 金手指 I2C 时钟 |
| 2 | +12V | 12V |
| 3 | I2C_SDA | 金手指 I2C 数据 |
| 4 | +24V | 24V |
| 5 | BOARD_NUM | 板号 R-2R 电压 |
| 6 | GND | 地 |
| 7 | BIT0 | 槽位 bit0 |
| 8 | GND | 地 |
| 9 | BIT1 | 槽位 bit1 |
| 10 | 3V3 | 3.3V |

槽位编码：

| 插座 | BIT1 | BIT0 | slot_id |
| --- | --- | --- | --- |
| CN1 | 0 | 0 | 0 |
| CN2 | 0 | 1 | 1 |
| CN3 | 1 | 0 | 2 |
| CN4 | 1 | 1 | 3 |

### 5.2 板号电压与判决

板号由大板 R-2R 产生，小板在 PA5 读：

| board_id | U1 U0 | 理想电压 | 带载约值 | 12 位代码 | 判决区间 |
| --- | --- | --- | --- | --- | --- |
| 0 | 00 | 0 V | 0 V | 0 | < 512 |
| 1 | 01 | 0.825 V | 0.78 V | 约 1024 | 512–1536 |
| 2 | 10 | 1.65 V | 1.56 V | 约 2048 | 1536–2560 |
| 3 | 11 | 2.475 V | 2.34 V | 约 3072 | > 2560 |

- 门限 0.41 / 1.24 / 2.06 V，对应代码 512 / 1536 / 2560。
- 必须用 3.3V 做 ADC 参考。
- 上电或插拔后延时 10–50ms，平均 8–16 次，连续 3 次同档才确认。

### 5.3 位置公式

```
position = board_id * 4 + slot_id + 1
```

范围 1–16。首板 H1 空置时 board_id=0；第 4 块板 11，H2 回绕 00，系统上限 4 块。

### 5.4 大板 H1/H2 级联

- 当前依据用 `JLC_modular_project/README.md` 第 3.3 节，H2→下一块 H1 不是直通。
- 旧的 `板号自动识别方案_精简版.md` 里 H1 引脚顺序是镜像写法，和当前 PDF/网表不一致，不要混用。
- 小板固件只需要读 BOARD_NUM/BIT0/BIT1，不需要驱动级联；级联测试属于大板 bring-up。

## 6. 固件测试工程设计

### 6.1 建议模块

| 模块 | 文件 | 内容 |
| --- | --- | --- |
| 时钟/延时 | `bsp_clock.c` | HSI 24MHz，SysTick 或 NOP 延时 |
| GPIO | `bsp_gpio.c` | 输出安全状态、输入初始化 |
| 板号/槽位 | `board_id.c` | PA5 ADC、PA6/PB3 输入、位置计算 |
| 本地 I2C2 | `bsp_i2c2_soft.c` | PA0/PA1 软件 I2C，100kHz，9 时钟恢复 |
| ADS1115 | `ntc.c` | 0x48，两次转换，R/T 换算，开路/短路判断 |
| 液位 | `level.c` | PA7 输入，3–5 次一致确认 |
| 输出 | `outputs.c` | PB1/PB2/PB0，高导通，先关断再配置 |
| 金手指 I2C | `bsp_i2c1.c` + `host_proto.c` | PA2/PA3，硬件 I2C1，AF12；从机地址/寄存器待定 |
| 调试串口 | `bsp_usart.c` | PF1 TX，115200 8N1 建议 |
| 测试入口 | `test_menu.c` | 编译期选择测试模式，或主机 I2C 命令 |

### 6.2 初始化顺序

1. 时钟：HSI 24MHz，配置 AHB/APB。
2. GPIO 安全状态：PB0/PB1/PB2 先输出低，再配置为输出；其他未用脚模拟输入。
3. USART TX：PF1，115200 8N1。
4. ADC：PA5，3.3V 参考，校准后采样。
5. 本地 I2C2：PA0/PA1 开漏，100kHz，发 9 个 SCL 脉冲恢复总线。
6. ADS1115：写配置，读 ID/结果。
7. 液位：PA7 输入。
8. 板号/槽位：延时、平均、判决。
9. 金手指 I2C：PA2/PA3，硬件 I2C1，AF12，按主机协议初始化从机。
10. 主循环或对应测试模式。

### 6.3 测试模式

小板 H1 没有 USART_RX，不能做 UART 命令行。测试入口用编译期宏，或通过金手指 I2C 主机下发：

```c
#define TEST_MODE_SELF     0
#define TEST_MODE_OUTPUT   1
#define TEST_MODE_SENSOR   2
#define TEST_MODE_HOST     3
#define TEST_MODE_POSITION 4
```

如果确实需要 UART 命令，把 PF0 接到 H1 pin3，配置为 USART_RX，再改 H1 线序。

## 7. 关键常量与公式

### 7.1 板号 ADC

- 12 位，3.3V 参考。
- 门限：512 / 1536 / 2560。
- 采样：延时 10–50ms，8–16 次平均，连续 3 次同档。

### 7.2 NTC / ADS1115

- 地址：0x48（ADDR 接 GND）。
- 第一次配置：`0x8383`，MUX=AIN0−AIN1，PGA=±4.096V，单次，128SPS。
- 第二次配置：`0xD383`，MUX=AIN1−GND。
- 转换等待：≥9ms，或轮询 OS 位。
- 换算：

```c
int16_t d = ads_read(0x8383);   // V_ntc
int16_t b = ads_read(0xD383);   // V_B
double R = 33000.0 * (double)d / (double)b;
double T = 1.0/(1.0/298.15 + log(R/10000.0)/3950.0) - 273.15;
```

- 38°C 对应 R≈5.751k，d/b≈0.1743。
- 探头开路：V_ntc≈3.3V，V_B≈0V。
- 探头短路：V_ntc≈0V，V_B≈3.29V。

### 7.3 液位

- PA7，干态高、湿态低。
- MCP6541 推挽，3.3V，无上拉。
- 翻转点约 R_w=220kΩ，迟滞窗口约 192–252kΩ。
- 软件连续 3–5 次一致再确认。

### 7.4 输出

- PB1=VALVE，PB2=PUMP，PB0=MOS。
- 高电平导通，低边 AO3400A。
- 复位后默认关断，100k 栅极下拉。
- J1/J4 是 12V，J2 是 24V，不要接反。

### 7.5 I2C

- 金手指：PA2/PA3，硬件 I2C1，AF12；大板 10k 上拉，4 块并联约 2.5k。
- 本地 I2C2：PA0/PA1，软件 I2C，开漏，R4/R5 4.7k。
- 两路总线不要混用。

## 9. 已知问题与待确认

1. **金手指 I2C 从机协议未定义**：从机地址、寄存器表、读写时序要和主机约定。F002A 的 I2C1 是否支持从机模式需查数据手册；不支持就要软件从机或改协议。
2. **R1–R8 槽位编码电阻值未标注**：原理图 Value 为空，JLC README 建议 10k，投板前补。未贴时 BIT0/BIT1 可能浮空。
3. **BOOT0 接法有差异**：小板 PDF 是 PB6/PF4-BOOT0 经电容到 GND，JLC README 写直接 GND。固件按 BOOT0=0、从 Flash 启动处理，实物以网表为准。
4. **H1 没有 USART_RX**：pin3 打叉。需要命令行走线把 PF0 接到 H1 pin3。
5. **PA0/PA1 只能软件 I2C**：没有硬件 I2C 复用，时序靠 NOP/定时器，100kHz 起步。
6. **板号 ADC 必须 3.3V 参考**：内部参考会破坏比例测量。
7. **NTC 互换性**：通用探头 ±0.5% 阻值，38°C 单点标定后才能进 ±0.1°C；标定基准要 ≤0.05°C。
8. **液位依赖水质**：自来水/加湿水 R_w 约 10–50kΩ；冷凝水可能几百 kΩ，当前 R7=220kΩ 会误判干。
9. **24V 安全**：J2 是 24V，J1/J4 是 12V；首次测试用限流电源，负载断开先测栅极。
10. **旧 KiCad `modular_slot_controller` 不是当前依据**：当前硬件是 JLC `.epro` 和 2026-11-20 的 PDF。
11. **大板 H1/H2 映射**：用 JLC README 第 3.3 节；旧的板号精简版 H1 表是镜像写法，不要混用。

## 11. 给接手 AI 的约束

- 以本 README 第 3 节和 2026-11-20 小板 PDF 为引脚唯一依据，不要从旧 KiCad 工程或旧文档猜引脚。
- 不要修改原理图、PCB、`.epro`；固件放在新目录 `firmware_test/`。
- 金手指 I2C 从机地址/寄存器未定，先做“能应答/能读 ID”的最小从机，协议等主机方确认。
- 首次上板先不接 12V/24V 负载，先测 3.3V、SWD、板号、槽位、输出栅极。
- 输出初始化必须先写低再切输出，避免上电瞬间误动作。
- 任何引脚冲突或文档不一致，先在 README 第 9 节记录，不要静默改硬件假设。
