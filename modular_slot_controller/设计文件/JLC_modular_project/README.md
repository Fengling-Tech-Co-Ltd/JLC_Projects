# 模块插槽拓展板（嘉立创 EDA 工程）交接说明

> 面向另一个工作区的 AI/工程师，用于继续原理图、PCB 和固件开发。
> 当前源文件：`JLC_拓展版_2026-11-18.epro`（立创EDA 专业版）。
> 本文的引脚和网络从该工程的 PCB 网表提取；旧版 KiCad `modular_slot_controller` 是中间版本，不作为当前依据。

## 1. 项目概述

模块化多槽位控制器，按 **4 块大板 × 4 块小板 = 16 个位置** 设计。

- **大板（拓展母板）**：4 个 10 芯金手指母座 CN1–CN4，板号链，槽位编码，3.3V LDO，上下级级联口 H1/H2，+24V/+12V/GND 分配。
- **小板（模块板）**：PY32F002AF15P6TU 主控，10 芯金手指 U1，NTC 测温，电导率液位检测，12V 泵/阀和 24V 负载输出，2×4 调试口。

系统信号流：

```
上一级/主机 ──H1/H2──> 大板1 ──H1/H2──> 大板2 ──> 大板3 ──> 大板4
                         │
                         ├── CN1 ──> 小板（位置 1）
                         ├── CN2 ──> 小板（位置 2）
                         ├── CN3 ──> 小板（位置 3）
                         └── CN4 ──> 小板（位置 4）
```

每块小板的位置 = 2 位板号（BOARD_NUM）+ 2 位槽位号（BIT0/BIT1）。

| H2 引脚 | 信号 | 下一块 H1 引脚 |

### 3.4 板号链

U1 SN74LVC2G86：

| 门 | 输入 | 输出 |
| --- | --- | --- |
| 1 | 1A=U0，1B=3V3 | 1Y=D0=~U0 |
| 2 | 2A=U1，2B=U0 | 2Y=D1=U1⊕U0 |

U1 引脚：1=U0，2=3V3，3=D1，4=GND，5=U1，6=U0，7=D0，8=3V3。

级联序列：00 → 01 → 10 → 11 → 00。首板 H1 空置时 R13/R14 把 U0/U1 拉成 00，H2 输出 D=01。

R-2R：

| 位号 | 阻值 | 连接 |
| --- | --- | --- |
| R9 | 2k 0.1% | U1 → BOARD_NUM |
| R10 | 1k 0.1% | BOARD_NUM → 中间节点 |
| R11 | 2k 0.1% | U0 → 中间节点 |
| R12 | 2k 0.1% | 中间节点 → GND |

`V_BOARD_NUM = 3.3 × (2·U1 + U0) / 4`

| 板号 | U1 U0 | 理想电压 | 带载约值 | 12 位代码 |
| --- | --- | --- | --- | --- |
| 1 | 00 | 0V | 0V | 0 |
| 2 | 01 | 0.825V | 0.78V | 1024 |
| 3 | 10 | 1.65V | 1.56V | 2048 |
| 4 | 11 | 2.475V | 2.34V | 3072 |

小板 ADC 判决门限约 0.41 / 1.24 / 2.06V，对应代码 512 / 1536 / 2560；最小裕量约 0.28V。小板 ADC 必须用 3.3V 参考，不能使用内部参考。

### 3.5 电源

- H1 输入 +12V/+24V，H2 继续向后传递。
- U2 AZ1117CR-3.3TRG1：+12V 输入，3.3V 输出，供 U1、I2C 上拉和 CN1–CN4 的 3V3。
- D1 SMF12CA 只保护 +12V；+24V 的保护在上游/背板，投板前确认。
- 4 块大板级联时，R15/R16 10k 上拉并联约 2.5k；若总线电容较大，确认 400kHz 上升沿，必要时只在一处装或降到 100kHz。

注意：

- 小板没有本地 LDO，3V3 来自大板金手指。
- 金手指 I2C（PA2/PA3）和本地 I2C2（PA0/PA1）是两路，不要混用。
- H1 调试口只引出了 USART_TX；USART_RX 未接。需要 RX 时把 U4 pin8（PF0）接到 H1 pin3，并配置为 USART_RX。
- PA5 必须是 ADC 输入；板号判决用 3.3V 参考。

### 4.4 NTC（U2 ADS1115）

- I2C2 地址 0x48（ADDR pin1 接 GND）。
- AIN0 = NTC_+，AIN1 = NTC_−。
- J5：pin2 NTC_+，pin1 NTC_−；探头 10k B3950。
- 分压：3V3 → R1 100Ω → NTC_+ → 探头 → NTC_− → R18 33k 0.1% → GND。
- R3 1k 到 AIN0，R2 1k 到 AIN1，C1/C6 100nF 到 GND。
- 采样：差分 AIN0−AIN1 得 V_ntc，单端 AIN1 得 V_B，比值算 R_ntc。
- 详细公式、误差预算和标定见 `电路设计方案\高精度NTC检测\`。

### 4.5 液位（U3 MCP6541）

- U3 引脚：1=WATER_LEVEL，2=GND，3=IN+，4=IN−，5=3V3。
- J3：pin1 探针，pin2 GND；2 根电极，单点检测。
- R7 220k 从 3V3 到探针，R13 1k 到 IN+，C4 100nF 到 GND。
- 阈值：R10 100k 3V3→IN−，R12 100k IN−→GND。
- 迟滞：R15 680k 从 WATER_LEVEL 到 IN−。
- 输出 WATER_LEVEL 接 PA7：干态高、湿态低。
- 阈值节点当前没有滤波电容（C5 是 3V3 去耦）；噪声环境下可在 U3 pin4 加 100nF。
- 详细原理和阈值计算见 `电路设计方案\电导率液位检测\`。

### 4.6 输出

| 输出 | MCU | 驱动 | 接口 | 负载 |
| --- | --- | --- | --- | --- |
| VALVE | PB1 | R6 10Ω → Q2 栅极，R9 100k 下拉 | J1 pin1 漏极，pin2 +12V | 12V 阀 |
| PUMP | PB2 | R14 10Ω → Q7 栅极，R17 100k 下拉 | J4 pin1 漏极，pin2 +12V | 12V 泵 |
| MOS | PB0 | R8 10Ω → Q4 栅极，R11 100k 下拉 | J2 pin1 漏极，pin2 +24V | 24V 负载 |

- 输出高电平导通，低边开关。
- D3 保护 J1，D7 保护 J4，D6 保护 J2。
- J1/J4 为 PH2.0 2P，J2 为 XH2.54 2P。

## 5. 位置计算

```
board_id = BOARD_NUM 判决值，0–3
slot_id  = (BIT1 << 1) | BIT0，0–3
position = board_id * 4 + slot_id + 1，1–16
```

- 首板 H1 空置：R13/R14 把 U0/U1 拉 00，board_id=0。
- H2 输出 D0/D1 到下一块 H1 的 U0/U1；级联线按 3.3 的映射。
- 第 4 块 11+1 回绕成 00；系统上限 4 块，不要接第 5 块。
- 中间缺一块大板，下面所有板号减一；链路单向无校验，必须连续安装。
- 槽位编码由大板 R1–R8 硬编码，小板只读 BIT0/BIT1。

## 6. 固件建议

建议按下面模块划分：

| 模块 | 内容 |
| --- | --- |
| `bsp_i2c` | 金手指 I2C（PA2/PA3）和本地 I2C2（PA0/PA1） |
| `board_id` | PA5 ADC 读 BOARD_NUM，判决 0–3 |
| `slot_id` | PA6/PB3 读 BIT0/BIT1 |
| `ntc` | ADS1115 0x48，差分 + 单端，比值算温度 |
| `level` | PA7 数字输入，消抖 |
| `outputs` | PB2 泵、PB1 阀、PB0 24V 负载 |
| `host_proto` | 金手指 I2C 从机协议（地址/寄存器待与主机约定） |

固件引脚汇总：

| 功能 | 引脚 | 脚号 |
| --- | --- | --- |
| 板号 ADC | PA5 | 7 |
| 槽位 BIT0 | PA6 | 6 |
| 槽位 BIT1 | PB3 | 4 |
| 液位输入 | PA7 | 16 |
| 泵输出 | PB2 | 18 |
| 阀输出 | PB1 | 19 |
| 24V 负载 | PB0 | 17 |
| I2C2 SDA | PA0 | 11 |
| I2C2 SCL | PA1 | 12 |
| 金手指 I2C SDA | PA2 | 13 |
| 金手指 I2C SCL | PA3 | 14 |
| USART TX | PF1 | 9 |
| SWDIO | PA13 | 2 |
| SWCLK | PA14 | 3 |
| NRST | PF2 | 10 |

固件 bring-up 顺序：

1. 大板：+24V/+12V/GND、3.3V LDO、U1 输出、BOARD_NUM 四档电压、CN1–CN4 槽位编码。
2. 级联：4 块大板 H1/H2 按映射接线，确认首板 00、末板 11、H2 输出 00。
3. 小板：3V3、SWD、PA5 板号、PA6/PB3 槽位。
4. 小板传感器：I2C2 扫描 0x48、NTC 读数、PA7 液位。
5. 小板输出：PB2/PB1/PB0 分别点动 J4/J1/J2。
6. 金手指 I2C：与主机联调从机协议。

## 7. 已知问题与待确认

1. **R1–R8 槽位编码电阻值未标注**：原理图 Value 为空，建议 10k，投板前补。
2. **H1/H2 级联线**：不是 1↔1 直通，按 3.3 的映射做线；插合前用万用表确认电源/GND。
3. **金手指 I2C 上拉**：每块大板 10k，4 块并联约 2.5k；确认 400kHz 上升沿，必要时只装一处或降速。
4. **+24V 保护**：大板 D1 只保护 +12V；+24V 的 TVS/保险在上游/背板，确认。
5. **液位阈值节点无滤波电容**：C5 是 3V3 去耦；噪声环境下在 U3 pin4 加 100nF。
6. **H1 调试口无 USART_RX**：需要时把 U4 pin8（PF0）接到 H1 pin3。
7. **小板金手指 I2C 从机地址/协议未定义**：与主机约定寄存器表。
8. **大板 U3–U6 是轮廓符号**，不是器件；BOM 只算 U1/U2。
9. **旧版 KiCad `modular_slot_controller` 是中间版本**：MCU/电源/ADC 未完成，不能作为当前投板依据。
10. **NTC/液位探头型号**：NTC 按 10k B3950，液位按 2 电极电导率；换探头需重新标定/改阈值。
