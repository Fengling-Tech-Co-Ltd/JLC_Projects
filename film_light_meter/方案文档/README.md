## 推荐阅读顺序

第一次接触这个项目，建议按下面顺序：

1. **需求文档**：先知道验证板要回答什么问题、指标是多少。
2. **功能闭环确认**：先看哪些能、哪些不能，避免把已知架构限制当成故障。
3. **硬件方案**：屏、OPT3001、QMA、L020 引脚的具体接法。
4. **软件与固件**：双屏条带渲染、低功耗和接口注意事项。

按目录编号顺序读也可以，但“功能闭环确认”放在最后会先看到细节、后看到结论。

## 当前设计结论摘要

- 0.97 屏可以在 L020 上跑；1.54/1.22 全屏 UI 受 3KB SRAM 限制，走条带渲染，或换 F030/F003 的 8KB。
- 整机 5µA 休眠与 QMA 常开手势冲突，实际按 10–15µA、CR2032 约 2 年预期。
- RTC 24h ±2s 缺 LSE，无法达标。
- 刷新跌落 <0.3V 需要 100µF 缓冲，当前 57µF，需实测。
- 1.54/1.22 升压 15uH/3Ω 经计算可行，2.4V 下需实测 VGH/VGL。
- R10、R11 已去掉；固件要处理 BUSY 悬空、OPT INT 开漏和 I2C 休眠高电平。
