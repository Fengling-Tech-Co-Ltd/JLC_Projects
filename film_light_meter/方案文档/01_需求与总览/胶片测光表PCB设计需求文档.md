## 1. 验证板定位与目标

**本板是功能与功耗验证板，不是最终产品形态。** 不包含也不约束任何外观形态、佩戴结构、外壳配合设计——那些是后续产品板阶段的事。

**本板要回答的问题（按优先级）：**

1. **功耗是否成立**：整机休眠电流、单次事件电荷量、刷新电压跌落、低压工作边界——全部达到第 5 节指标，支撑"CR2032 续航 ≥2 年"的论断；
2. **核心功能链路是否跑通**：OPT3001 测光 → MCU 曝光换算 → 墨水屏局刷显示全链路；
2a. **双屏验证**：0.97″（GDEM0097T61，SSD1680，18Pin）与 1.54″（GDEY0154D67，SSD1681，24Pin）两款墨水屏均能点亮并完成局刷/全刷，为产品板屏幕选型提供显示效果与功耗的实测对照；
3. **交互是否成立**：QMA6100P 手势（抬腕/双击/自动转屏）、旋转编码器翻页手感与消抖策略；
4. **为产品板沉淀数据**：实测功耗台账、器件选型确认、固件状态机验证。

**验证成功标准：** 第 5 节全部功耗指标实测达标 + 第 9 节全部功能用例通过。

## 2. 系统架构

```
                 CR2032 (3.0V, 直挂无LDO)
                    │
            [J1 跳线测量点]── 100µF 缓冲电容
                    │
        ┌───────────┼─────────────┬──────────────┬───────────┐
        │           │             │              │           │
   PY32L020   墨水屏×2款     OPT3001       QMA6100P    旋转编码器
   /PY32F030  0.97" T61     (照度传感器)   (加速度计)   (A/B相+按压)
   (MCU)      1.54" D67     USON-6         LGA-12
   TSSOP20    (二选一插接)
        │      SPI×1 共享     │              │
        └──── I2C 共总线 ─────┴──────────────┘
              (SDA/SCL + 4.7kΩ 上拉)

   其他：32.768kHz 晶振 │ SWD 调试口 │ PPK2 测试接口 │ 复位键 │ GPIO 标记脚×2
```

**设计要点：** 全系统无 LDO，电池直接供电；全部数字器件共用 3.0 V 单电源域。用户输入设备为**旋转编码器**（替代传统按键）。

## 4. 电气设计要求

### 4.1 电源架构

- **无 LDO**，CR2032（标称 3.0 V，工作区间 2.0–3.3 V）直接供电。全器件电压兼容性：

| 器件 | 电压范围 | 结论 |
|---|---|---|
| PY32L020 | 1.7–5.5 V | 全程覆盖 |
| OPT3001 | 1.6–3.6 V | 全程覆盖（选它的原因之一） |
| QMA6100P | 1.71–3.6 V | 全程覆盖 |
| GDEM0097T61 | ≈2.2–3.6 V | 电池跌至 2.2 V 为系统下限 |

- 电池入口：**100 µF 缓冲电容**（C1）+ 每芯片 VCC 就近 100 nF 去耦；
- 测量跳线 J1 位于**电池正极与 100 µF 电容之间**（缓冲电容属于被测系统，必须在测量点之后）；
- 电池防反接依赖电池座结构防呆，不额外加二极管（压降浪费电压余量）。

### 4.2 总线

| 总线 | 设备 | 上拉 | 备注 |
|---|---|---|---|
| I²C（100/400 kHz） | OPT3001（0x44）+ QMA6100P（0x12）共总线 | 4.7 kΩ ×2，靠近 MCU | **休眠时 SDA/SCL 必须都为高电平**，否则上拉电阻持续漏电 ≈640 µA |
| SPI | 墨水屏 ×2 座（SCK/MOSI/CS/DC/RST + BUSY 输入，两座信号并联） | 无需 | BUSY 必须接带外部中断能力的 GPIO。**两座同时上板但任一时刻只插一块屏**；不插屏的座保持空置，信号走线尽量短以减少未插座的 stub 影响 |

### 4.3 旋转编码器接口

- **A/B 相**：各接一路 MCU GPIO，使用 MCU 内部上拉（编码器公共端接地）；**A 相必须接带外部中断能力的脚**（边沿触发 + 固件正交解码），B 相普通 GPIO 即可；
- **按压开关**（若所选型号带按压）：接 Stop 模式可唤醒的中断脚——这是无按键方案下的重要唤醒入口；
- **消抖**：优先固件消抖（计时器状态机），板上预留 RC 消抖焊盘（10 kΩ + 100 nF，默认不贴）；
- 机械编码器触点电流极小（<1 mA），无驱动能力要求。

### 4.4 中断与唤醒

| 信号 | 方向 | 要求 |
|---|---|---|
| QMA6100P INT1 | → MCU | Stop 可唤醒外部中断脚（抬腕/运动唤醒主通道） |
| QMA6100P INT2 | → MCU | 双击手势通道，需唤醒能力 |
| 编码器按压 | → MCU | Stop 可唤醒中断脚（若型号带按压） |
| 编码器 A 相 | → MCU | 外部中断脚（活跃期旋转解码，不承担休眠唤醒） |
| OPT3001 INT | → MCU | **预留焊盘即可，本版固件不使用**（轮询方案） |
| 墨水屏 BUSY | → MCU | 外部中断脚，刷新等待期间 MCU 进 Sleep |

### 4.5 MCU 引脚预算（TSSOP20 共 18 IO，晶振占 2 脚后余 16）

| 功能 | 脚数 | 备注 |
|---|---|---|
| LSE 晶振 | 2 | **PC1（OSCIN）、PB7（OSCOUT），被晶振占用** |
| SPI（SCK/MOSI/CS/DC/RST/BUSY） | 6 | 墨水屏 |
| I²C（SDA/SCL） | 2 | 两传感器共用 |
| QMA6100P INT1/INT2 | 2 | |
| 编码器 A 相 / B 相 | 2 | A 相需中断能力 |
| 编码器按压 | 1 | 需唤醒能力（无按压型号则释放此脚） |
| SWD（SWDIO/SWCLK） | 2 | 烧录后复用为 GPIO 标记脚 |

合计 17 ≤ 18，**刚好排布**；OPT3001 INT 不占脚（预留上拉焊盘）。若所选编码器不带按压，需再确认唤醒路径是否完全交给 QMA6100P（可接受）。

### 4.6 墨水屏驱动电路（双屏座设计）

- 板上同时布置 **两座驱动电路**，相互独立：
  - **LCD1 座（18Pin）**：GDEM0097T61 用，严格按 **SSD1680** datasheet 推荐应用电路布置外围（电荷泵电容组等，约 5–8 颗），参考 Good Display 官方 GDEM0097T61 参考设计；
  - **LCD2 座（24Pin）**：GDEY0154D67 用，严格按 **SSD1681** datasheet 推荐应用电路布置外围，参考 Good Display 官方 GDEY0154D67 参考设计。**注意 SSD1681 与 SSD1680 外围电路和 FPC 引脚定义不同，不可互套**；
- 两座信号线（SPI + DC/RST/BUSY）并联至 MCU 同一组引脚，**任一时刻只插一块屏**；两座 VCC 各自预留 **P-MOS 高边开关位置**（默认贴 0 Ω 直连；若实测屏待机电流超标再启用 MOS）；
- FPC 座：18Pin 与 24Pin 各一，0.5 mm 翻盖下接式，布局时两座分开摆放、互不遮挡，便于插拔对照测试。

### 4.7 其他

- OPT3001 光窗区域：焊盘上方**禁止铺铜和走线**，阻焊开窗按 datasheet 要求；
- 所有未用 GPIO 固件配为模拟输入或推挽输出（防浮空漏电）；
- 编码器外壳焊盘接地。

## 5. 功耗设计目标与验收标准

| 项目 | 目标值 | 测量方法（PPK2） |
|---|---|---|
| 整机休眠电流 | **≤ 5 µA** | 源表模式 3.0 V，固件进纯休眠测试模式，10 min 平均 |
| 单次轮询电荷 | ≤ 0.15 µAh | 框选单次唤醒波形积分 |
| 单次局刷电荷 | ≤ 0.3 µAh（两款屏分别实测记录：T61 约 0.17 µAh / D67 约 0.13 µAh 为理论值） | 触发捕获局刷事件积分，两款屏各测一次 |
| 典型日功耗 | ≤ 0.2 mAh（对应 CR2032 ≈ 2.5 年） | 完整固件模拟使用剧本 30 min 外推 |
| 刷新电压跌落 | VDD 谷值跌落 < 0.3 V | 供电串 10–15 Ω 模拟电池内阻 + 示波器测 VDD 测试点 |
| 低压功能 | 2.2 V 下测光/刷新/唤醒全部正常 | PPK2 电压扫描 3.3→2.2 V |

## 6. 验证板机械约束（最小化）

**原则：可测试性优先于尺寸。**

- 尺寸不限，建议 ≤ 60 × 40 mm 便于手持测试；双面板，板厚 1.0–1.2 mm；
- 元件尽量单面（顶面）布局，便于探针和观察；
- 编码器靠板边安装，旋转操作时手不遮挡屏幕和传感器光窗；
- 屏幕经 FPC 平铺于板旁即可，无需定型弯折（FPC 弯折半径 ≥1 mm）；
- 所有测试点/排针留有插拔和夹表笔的空间；
- 传感器光窗正上方保持空旷，验证时漫射罩用乳白胶带/热缩管临时模拟即可。

## 7. 测试与调试接口（必须全部落板）

### 7.1 PPK2 功耗测量接口（3P 2.54mm 排针 + 跳线帽）

```
BAT+ ──┬──[J1 跳线]──┬── 100µF ── 系统VDD
       ①             ②
BAT- ──┴──── GND ────┴── ③ GND 测试点
```

- 拔掉跳线帽 + 取出电池 → PPK2 源表模式 VOUT 接②、GND 接③（仿真电池并测功耗）
- PPK2 串联①②之间 → 电流表模式（真实电池工况）
- ①②间走线 ≥0.5 mm 宽且尽量短，降低测量串联电阻

### 7.2 测试点清单

| 编号 | 信号 | 用途 |
|---|---|---|
| ①② | 电池侧/系统侧电源排针 | PPK2 接入 |
| ③ | GND ×2（分开布局） | 仪器地线 |
| ④ | VDD 焊盘 | 示波器测刷新跌落 |
| ⑤ | 墨水屏 VCC（MOS/直连点之后） | 验证休眠时屏电源状态 |
| ⑥ | GPIO 标记脚 ×2（与 SWD 复用） | 接 PPK2 逻辑通道，固件状态标记 |
| ⑦ | SWD 排针（SWDIO/SWCLK/GND） | **不接 VCC**，避免调试器反向供电污染功耗测量 |
| ⑧ | 调试 LED + 断开焊盘跳线 | Bring-up 指示，测功耗时断开 |
| ⑨ | NRST 复位按键 | 验证板调试 |

## 8. 布局布线要点

1. 电源主干走线 ≥0.5 mm；电池座 → 跳线 → 缓冲电容路径最短化；
2. 32.768 kHz 晶振紧贴 MCU（PC1/PB7），走线对称短直，下方铺地；
3. I²C 上拉靠近 MCU；总线避免与 SPI 长距离并行；
4. OPT3001 光窗正上方及周围按 datasheet 挖空铺铜，远离墨水屏电荷泵回路等大电流脉冲走线；
5. QMA6100P 丝印明确标 1 脚方向（**方向贴反手势轴向全错**），贴片图同步标注；
6. 编码器外壳焊盘良好接地（兼作机械固定和 ESD 泄放）；
7. 测试点分布板边四周，便于探针/夹具；
8. 丝印：测试点编号、电池极性、屏 FPC 方向、各 IC 一脚标记。

## 9. 固件配合需求（功能验证用例）

### 9.1 功耗测试固件（三个模式）

1. **纯休眠**：初始化外设后直接进 Stop，验收休眠电流；
2. **轮询不刷屏**：周期性唤醒读 OPT3001 不回写屏幕，验收单次轮询电荷；
3. **完整流程**：正常逻辑运行，配合模拟使用剧本验收日均功耗。

| 7 | 编码器消抖 | 快速正反转无跳格、无丢步 |
| 8 | 休眠保显 | 进入 Stop 后屏幕内容保持，唤醒后续显正常 |
| 9 | 低压流程 | 2.2 V 供电下用例 1/2/4 全部通过 |
| 10 | 时钟走时 | RTC + LSE 运行 24 h，误差 ≤ ±2 s（±20 ppm 量级） |
| 11 | 双屏点亮 | 两款屏分别插接，各自完成初始化→全刷→局刷→deep sleep 全流程，波形 LUT 用对应屏官方版本（SSD1680/SSD1681 不通用） |
| 12 | 双分辨率 UI 适配 | 同一套 UI 代码在 184×88 与 200×200 两种分辨率下正确渲染（帧缓冲尺寸与布局参数化）；**测 1.54″ 屏时 MCU 必须为 PY32F030**（3KB SRAM 装不下 5000 B 帧缓冲） |

### 9.3 GPIO 标记约定

PA_x 唤醒拉高/入睡拉低，PA_y 刷屏期间翻转（具体引脚待原理图分配后回填本文档）。

### 9.4 休眠断电纪律（功耗达标的关键）

休眠前：墨水屏进 deep sleep → OPT3001 发 shutdown → QMA6100P 切 2 µA 档 → 确认 I²C 总线释放为高 → 未用 GPIO 全部置模拟输入。
