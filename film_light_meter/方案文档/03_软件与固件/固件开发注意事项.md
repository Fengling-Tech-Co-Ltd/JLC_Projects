# 胶片测光板固件开发注意事项

| 项目 | 内容 |
| --- | --- |
| 项目 | 胶片相机测光板（验证板） |
| 版本 | v1.0 |
| 日期 | 2026-11-19 |
| 适用硬件 | 原理图 `../../设计文件/胶片相机测光_2026-11-19.pdf`，R10/R11 已去掉，R8/R9 保留 |
| 用途 | 固件开发时避免 I2C 漏电、BUSY 误判、OPT INT 悬空等问题 |

## 1. I2C 上拉与休眠漏电

当前硬件：R8、R9 为 4.7kΩ 上拉到 3V3，挂在 PB3/PB4，总线上有 OPT3001（0x44）和 QMA6100P（0x13）。

结论：**4.7kΩ 上拉本身没有问题，不需要改。**

| 总线状态 | 单条线电流 | 说明 |
| --- | --- | --- |
| 空闲高 | nA 到 µA 级 | 只有 MCU 和传感器输入漏电，可以忽略 |
| 传输时拉低 | 约 640µA | 3.0V / 4.7k，只在低电平期间 |
| 休眠时被某器件拉住低 | 约 640µA 持续 | 需求文档要避免的就是这种情况 |

固件要求：

- 进入 Stop 前，MCU 的 I2C 引脚保持开漏高或高阻，不能输出低。
- OPT3001 发 shutdown，QMA6100P 进 Standby，两者释放总线。
- 确认没有器件做时钟拉伸，SDA、SCL 都被上拉为高。
- 纯休眠测试时量 SDA、SCL 电平；哪条低就查是哪个器件拉住。
- 如果传感器用的是带板载上拉的模块，模块上拉会和 R8/R9 并联，等效阻值变小，拉低电流更大；先确认模块有没有上拉。
- 4.7k 对 400kHz 合适。不要为了省电改成 10k，400kHz 下上升沿可能不合规；2.2k 反而更费电。

## 2. BUSY / PB2，R11 已去掉

- 两款屏的 BUSY 都是推挽输出，参考电路没有外部上拉，正常插屏时由屏直接驱动。
- 空闲低、忙时高；发刷新命令后等 BUSY 变低。
- 没插屏或没装跳线时，PB2 悬空。固件要么在“未选屏”分支不读 BUSY，要么临时开内部下拉，读完再关。
- 屏进 deep sleep 后 BUSY 会保持高（SSD1681 的 0x10 命令）。入睡前把 PB2 设成模拟输入或浮空，不要留内部下拉，否则会被灌几十 µA。
- 去掉 R11 避免了屏空闲时 300µA 的上拉电流，这是对的。
- 如果实测 0.96 屏 BUSY 高电平上不去，再补 100k 上拉；正常情况下不需要。

## 3. OPT3001 INT / PA4，R10 已去掉

- OPT3001 的 INT 是开漏输出，没有上拉时中断功能不可用。
- 当前固件用轮询，可以不加 R10。
- PA4 不能悬空：
  - 不用中断：PA4 配成模拟输入，OPT INT 拉低也不会有数字输入电流；或 PA4 开内部上拉，同时把 OPT3001 的高/低阈值配好，别让它常拉低。
  - 以后要用中断：把 R10 加回来，10k 到 3V3；按手册读状态/配置清中断。
- 如果 PA4 配成普通数字输入又没有上下拉，OPT INT 高阻时 PA4 会悬空，可能出现数字输入漏电或误读。

## 4. QMA6100P INT / 编码器 / SPI 切换

- QMA INT1/INT2 是推挽输出，接 PC1/PB7，不需要外部上拉；如果以后配成开漏，再加 10k。
- 编码器 A/B/按键各有 10k 上拉，固件做消抖，不要依赖硬件 RC。
- SPI 切换排针每个只插一个跳线帽；插两个会把两块屏的 BUSY 输出短在一起。
- 未选中屏的 RES/D/C/CS/SCK/MOSI 会悬空；验证时一次只插一块屏，或给每块屏加 100k 上拉/下拉。

## 5. 低功耗休眠顺序

1. 墨水屏发 deep sleep，BUSY 会保持高。
2. OPT3001 发 shutdown。
3. QMA6100P 切 Standby。
4. 确认 I2C 总线 SDA/SCL 都为高，MCU 的 I2C 引脚不要驱动低。
5. PB2（BUSY）设模拟输入或浮空；PA4（I2C_INT）设模拟输入或按需上拉。
6. 未用 GPIO 全部设模拟输入，避免浮空漏电。
7. MCU 进 Stop，使用 LPR 低功耗稳压器，不进 MR。
8. 调试器断开，J1 的 3V3 不接，H7/H8 电池跳线按测量方式处理。

注意：L020 Stop 典型 1.5µA，QMA 最低 5µA，OPT3001 1.8µA，屏 1µA，合计约 9.3µA。5µA 整机目标与 QMA 常开手势冲突，实测按 10–15µA 预期。

## 6. Bring-up 检查

- [ ] I2C 扫描能看到 OPT3001 0x44、QMA6100P 0x13。
- [ ] 插屏并选通跳线后，BUSY 空闲低、忙时高。
- [ ] 未插屏或未装跳线时，固件不会卡在 BUSY 等待。
- [ ] 屏 deep sleep 后 PB2 为高，MCU 没有开内部下拉。
- [ ] PA4 不用中断时为模拟输入，或已加上拉并配好阈值。
- [ ] 纯休眠时 SDA、SCL 都为高，整机电流符合预期。
- [ ] 局刷、全刷、每 20–50 次局刷后的全刷都正常。
- [ ] 2.4V 低压下刷新和唤醒正常。
