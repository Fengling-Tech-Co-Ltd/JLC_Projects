# GDEY0154D67 24Pin 接线与布局方案

> 适用：胶片相机测光板验证板的 1.54″ 墨水屏（GDEY0154D67，SSD1681，200×200，24Pin 0.5mm FPC）。
> 依据：GDEY0154D67 数据手册第 7 页引脚表、第 28 页参考电路；SSD1681 数据手册第 12 节应用电路。
> 本文只覆盖屏幕接口、升压外围和布局，不改变整体板级需求。

## 1. 24Pin FPC 接线表

| 脚 | 名称 | 接到哪里 | 外围/备注 |
| --- | --- | --- | --- |
| 1 | NC | 悬空 | 不要和其他 NC 相连 |
| 2 | GDR | Q1 栅极 | R1 1MΩ 从 GDR 到 GND |
| 3 | RESE | Q1 源极 | 接 R2 2.2Ω 上端，走线短 |
| 4 | NC | 悬空 | 不要和其他 NC 相连 |
| 5 | VSH2 | 1µF/25V 到 GND | 靠近 pin5 |
| 6 | TSCL | 悬空 | 屏内部温度传感器 I2C 主时钟，本设计不用 |
| 7 | TSDA | 悬空 | 屏内部温度传感器 I2C 主数据，本设计不用 |
| 8 | BS1 | GND | 选 4 线 SPI；靠近 pin8 接地 |
| 9 | BUSY | MCU GPIO | 建议用带中断的输入；远离升压 SW 节点 |
| 10 | RES# | MCU GPIO | 低有效复位；10kΩ 上拉到 3.3V |
| 11 | D/C# | MCU GPIO | 数据/命令选择 |
| 12 | CS# | MCU GPIO | 低有效片选；10kΩ 上拉到 3.3V |
| 13 | SCL | MCU SPI SCK | 4 线 SPI |
| 14 | SDA | MCU SPI MOSI | 屏只写，不需要 MISO |
| 15 | VDDIO | 3.3V | 与 VCI 同轨；C6 1µF/25V 到 GND |
| 16 | VCI | 3.3V | 与 VDDIO 同轨；C6 1µF/25V 到 GND |
| 17 | VSS | GND | 多点接地到地平面 |
| 18 | VDD | 只接 C7 1µF/25V 到 GND | **不能接 3.3V**，VDD 是内部稳压输出 |
| 19 | VPP | 悬空 | 测试脚，不引出 |
| 20 | VSH1 | 1µF/25V 到 GND | 靠近 pin20 |
| 21 | VGH | 1µF/25V 到 GND | 同时接 D3 阴极/PREVGH |
| 22 | VSL | 1µF/25V 到 GND | 靠近 pin22 |
| 23 | VGL | 1µF/25V 到 GND | 同时接负压电荷泵 PREVGL |
| 24 | VCOM | 1µF/25V 到 GND | 靠近 pin24 |

所有 1µF 电容用 X5R/X7R、25V 耐压、0603/0805。

## 2. 升压与负压外围

SSD1681 需要外加升压电路，不能只给 3.3V。

| 器件 | 参数 | 接法 |
| --- | --- | --- |
| C4 | 4.7µF/25V | 3.3V 到 GND，靠近 L1 输入端 |
| L1 | 47µH/500mA | 3.3V 到 SW 节点 |
| Q1 | Si1308EDL 或 NX3008NBK | 漏极=SW 节点，源极=R2 上端，栅极=GDR |
| R1 | 1MΩ | GDR 到 GND |
| R2 | 2.2Ω/1% | Q1 源极到 GND；RESE 接源极 |
| D3 | MBR0530 | 阳极=SW 节点，阴极=PREVGH/VGH |
| C5 | 1µF/25V | PREVGH 到 GND |
| C3 | 4.7µF/25V | SW 节点到 flying 节点 |
| D1/D2 | MBR0530 | 负压电荷泵，方向严格按 GDEY0154D67 数据手册第 28 页参考电路 |
| VGL 电容 | 1µF/25V | PREVGL 到 GND |

关键点：

- GDR、RESE、SW 节点、D3、C5 构成升压主回路，面积越小越好。
- VGH 可到约 20V，VGL 为负压，VSH1/VSH2 也为高压；这些节点不要引出测试点，不要裸露铜皮。
- VDD（pin18）是内部稳压输出，只挂 1µF 电容，不能接 3.3V。
- VPP（pin19）悬空。
- TSCL/TSDA（pin6/7）悬空，不布线。

## 3. 布局方案

### 3.1 FPC 座

- 24Pin、0.5mm 间距、下接翻盖式 FPC 座，放在板边，pin1 丝印清晰。
- FPC 座正下方和前方留 2–3mm 插拔空间，不放过孔和器件。
- 屏 FPC 平铺在板旁，弯折半径 ≥1mm；验证板不做定型弯折。
- pin1 方向按屏排线金手指面和座子丝印，首件用万用表确认。

### 3.2 升压回路

- L1、Q1、D3、C3、C4、C5 紧靠 FPC 的 pin2/3/21/23 一侧，主回路走线短而粗。
- SW 节点（L1-Q1-D3 交汇点）面积尽量小，避免向周围辐射。
- Q1 源极到 R2 的走线短；RESE 从 R2 上端单独取样，避免和大电流地混在一起。
- GDR 到 Q1 栅极的走线短，R1 靠近栅极。
- C5 靠近 D3 阴极和 pin21；C2/C9/C10/C11/C12 分别靠近 pin5/20/22/23/24。
- 高压节点（VGH、VGL、VSH1、VSH2、VSL、VCOM）与低压 SPI/传感器走线保持 ≥0.5mm 间距；按板厂工艺留爬电距离。
- 高压节点下方尽量完整地平面，不跨分割；不要在 FPC 座下方走高压线。

### 3.3 电源与地

- C4 的 GND、Q1 源极/R2 的 GND、C5/C9-C12 的 GND 回到同一片功率地，再单点接到系统 GND。
- 3.3V 到 VDDIO/VCI 的走线短，C6 靠近 pin15/16；C7 靠近 pin18。
- FPC 的 VSS（pin17）多点接地到地平面。
- 升压开关噪声大，尽量远离 OPT3001 光窗和 QMA6100P；必要时在两者之间加地缝/屏蔽地。
- 显示升压回路不要和 I2C、SPI 长距离平行。

### 3.4 信号走线

- SCL/SDA/D/C#/CS#/RES# 走线短，SPI 起始限制在 2MHz 以内。
- BUSY 接 MCU 外部中断，走线避让 SW 节点和 L1。
- BS1 在 pin8 附近直接接地，不要拉长。
- RES#/CS# 的 10kΩ 上拉靠近 MCU 或 FPC 座。
- 可选：SCK/SDA 串 22Ω，靠近 MCU，抑制过冲；默认不贴。
- 不用的 TSCL/TSDA/VPP 不引出，不留长 stub。

### 3.5 双屏座

- 0.97″ 与 1.54″ 两座分开摆放，各自一套升压/电容，互不遮挡，便于插拔对照。
- 两座 SPI/DC/RES/BUSY 信号并联；未插屏的座保持空置，stub 尽量短。
- 若双座同时贴升压件，未插屏的那套不会工作（屏内 IC 不在），但电容和走线仍会形成 stub；必要时用 0Ω 电阻隔离。
- 成本敏感时可只贴当前验证屏的升压件，另一座预留焊盘。

### 3.6 ESD 与测试

- FPC 座是板边接口，装配时注意 ESD；调试时先接屏再上电。
- 高压节点不设测试点；只保留 3.3V、GND、SPI 信号的测试点。
- 首件检查：pin1 方向、VDD 只挂电容、VPP 悬空、BS1 接地、VGH/VGL 电容方向。

## 4. 布局检查清单

- [ ] FPC pin1 方向与座子丝印一致，24Pin 0.5mm。
- [ ] pin18 VDD 只接 1µF 到 GND，没有接 3.3V。
- [ ] pin19 VPP 悬空，pin6/7 TSCL/TSDA 悬空。
- [ ] pin8 BS1 已接地，4 线 SPI。
- [ ] GDR/RESE 走线短，R2 2.2Ω 靠近 Q1 源极。
- [ ] L1/Q1/D3/C3/C4/C5 升压回路面积小，SW 节点短。
- [ ] VGH/VGL/VSH1/VSH2/VSL/VCOM 电容靠近对应引脚。
- [ ] 高压节点与 SPI/传感器走线保持间距，无裸露测试点。
- [ ] 升压回路远离 OPT3001 光窗和 QMA6100P。
- [ ] 双屏座分开，未插座的 stub 短，必要时 0Ω 隔离。
- [ ] 3.3V、GND、SPI 测试点可探，高压节点不可探。
