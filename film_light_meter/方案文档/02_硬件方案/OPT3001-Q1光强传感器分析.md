# OPT3001-Q1 光强传感器分析

> 适用：胶片相机测光板验证板的环境光测量。
> 器件：OPT3001-Q1，环境光传感器（ALS），光电二极管 + ADC + I2C。
> 当前硬件：ADDR 引脚接 GND，7 位 I2C 地址 0x44。

## 1. 器件定位与关键参数

| 项目 | 内容 |
| --- | --- |
| 类型 | 环境光传感器，内置光电二极管、ADC、I2C |
| 量程 | 0.01–83k lux |
| 有效动态范围 | 23 位 |
| 供电 | 1.6–3.6 V |
| 典型工作电流 | 1.8 µA |
| 接口 | I2C / SMBus，100/400 kHz |
| 封装 | USON-6（具体以数据手册封装图为准） |
| 中断 | INT 开漏输出，需 10kΩ 上拉 |
| 车规 | Q1 版本，寄存器与地址规则与标准 OPT3001 一致 |

测光表需求是 10–10000 lux、误差 ≤ ±1/3 EV；OPT3001-Q1 的量程覆盖，实际精度取决于漫射罩、安装角度和整机标定。

## 2. I2C 地址

ADDR 引脚决定 7 位地址：

| ADDR 接法 | 7 位地址 | 8 位写/读 |
| --- | --- | --- |
| GND | 0x44 | 0x88 / 0x89 |
| VDD | 0x45 | 0x8A / 0x8B |
| SDA | 0x46 | 0x8C / 0x8D |
| SCL | 0x47 | 0x8E / 0x8F |

当前设计 **ADDR=GND → 0x44**。代码里如果驱动库要求 8 位地址，写 0x88、读 0x89。

I2C 总线上还有 QMA6100P（0x12），两者不冲突。上拉 4.7kΩ 到 3.3V，总线 400kHz。

## 3. 寄存器

| 地址 | 寄存器 | 说明 |
| --- | --- | --- |
| 0x00 | Result | 16 位测量结果，只读 |
| 0x01 | Configuration | 配置寄存器 |
| 0x02 | Low Limit | 低阈值 |
| 0x03 | High Limit | 高阈值 |
| 0x04 | Manufacturer ID | 固定 0x5449 |
| 0x05 | Device ID | 固定 0x3001 |

上电自检可先读 0x04/0x05，确认 0x5449/0x3001。

## 4. lux 换算

Result 寄存器 16 位：

- bit15:12 = E[3:0]，指数
- bit11:0 = R[11:0]，尾数

```
lux = 0.01 × 2^E × R
```

例：读回 0x3456：

```
E = 0x3 = 3
R = 0x456 = 1110
lux = 0.01 × 2^3 × 1110 = 88.8 lux
```

## 5. 配置寄存器

默认值 0xC810：掉电、800ms、自动量程。

| 模式 | 配置字 |
| --- | --- |
| 连续，800ms，自动量程 | 0xCA10 |
| 单次，800ms，自动量程 | 0xC910 |
| 连续，100ms，自动量程 | 0xC210 |
| 单次，100ms，自动量程 | 0xC110 |

说明：

- CT=1 为 800ms，CT=0 为 100ms。
- M[1:0]=10 连续，M[1:0]=01 单次，00 掉电。
- 低功耗测光建议单次模式：写配置 → 等转换 → 读 Result → 写回掉电。
- 自动量程是默认 RN=1100b，Result 的 E 位会随量程变化。

## 6. 中断

- INT 是开漏输出，需要 10kΩ 上拉到 3.3V。
- 当前测光表方案用轮询，INT 只预留焊盘，不接 MCU。
- 如果后续改成中断唤醒，把 INT 接到 MCU 的外部中断脚，并在配置里设置高/低阈值。

## 7. 布局与光学

- 光窗正上方和周围禁止铺铜、走线；按数据手册开阻焊窗。
- 光窗远离墨水屏升压回路、L1、Q1、D1–D3 等开关节点。
- 器件靠近板边或外壳开窗，避免被屏幕 FPC、排线遮挡。
- 漫射罩先用乳白胶带/热缩管临时模拟，标定时再定正式光学件。
- 3.3V 引脚就近放 100nF 去耦。
- ADDR 已接 GND，地址固定 0x44，不要再改。

## 8. 上电与读取流程

1. 3.3V 上电，等 1–5ms。
2. 读 Manufacturer ID（0x04）应为 0x5449，Device ID（0x05）应为 0x3001。
3. 写配置：
   - 连续测量：0xCA10 或 0xC210；
   - 单次测量：0xC910 或 0xC110。
4. 等转换完成：
   - 800ms 模式等 800ms 以上；
   - 100ms 模式等 100ms 以上；
   - 或用 INT 判断。
5. 读 Result（0x00）2 字节，按第 4 节换算 lux。
6. 单次模式读完后写回掉电配置（0xC810 或 0xC010），降低平均功耗。
7. 多次平均，做整机标定。

## 9. 与测光表需求的对应

| 需求 | OPT3001-Q1 对应 |
| --- | --- |
| 10–10000 lux | 量程 0.01–83k lux，覆盖 |
| ±1/3 EV | 器件精度足够，需整机漫射罩/角度标定 |
| 休眠 ≤5 µA | 器件掉电，I2C 总线释放为高；上拉不持续漏电 |
| 2.2 V 低压工作 | 器件 1.6–3.6 V，覆盖 |
| I2C 与 QMA6100P 共总线 | 0x44 与 0x12 不冲突 |
| 低功耗轮询 | 单次 100ms/800ms + 掉电 |

## 10. 检查清单

- [ ] ADDR 接 GND，地址 0x44。
- [ ] 3.3V 就近 100nF 去耦。
- [ ] I2C 上拉 4.7kΩ 到 3.3V，和 QMA6100P 共总线。
- [ ] 光窗下无铺铜、无走线，阻焊开窗。
- [ ] 光窗远离墨水屏升压和发热器件。
- [ ] INT 若使用，10kΩ 上拉并接 MCU 中断脚；不用则留焊盘。
- [ ] 上电先读 0x5449/0x3001 自检。
- [ ] 单次测量后写回掉电，保证休眠功耗。
