# QMA6100P 姿态传感器分析

> 适用：胶片相机测光板验证板的抬腕唤醒、双击唤醒、自动转屏。
> 器件：QMA6100P，三轴 MEMS 加速度计，LGA-12 2×2×0.95mm。
> 依据：QST QMA6100P 数据手册 Rev A1（Preliminary）。

## 1. 器件定位与关键参数

| 项目 | 内容 |
| --- | --- |
| 类型 | 三轴 MEMS 加速度计，内置运动算法 |
| 量程 | ±2 / ±4 / ±8 / ±16 / ±32g |
| 分辨率 | ±2g 时 244µg/LSB；±4g 时 488µg/LSB |
| 输出 | 14 位补码 |
| ODR | 1.25–1000Hz |
| 供电 | 1.71–3.6V |
| 待机电流 | 0.5µA |
| 低功耗工作电流 | 5–44µA，随 ODR 变化 |
| 低噪声工作电流 | 38–149µA |
| 接口 | I2C 100/400kHz；SPI 3/4 线 |
| 地址 | 7 位 0x12 / 0x13，由 AD0 决定 |
| FIFO | 64 帧 |
| 封装 | LGA-12，2×2×0.95mm |
| 工作温度 | -40–85°C |

内置功能：STEP、TAP、RAISE、ANY_MOT、SIG_MOT、NO_MOT、FIFO、DRDY 等中断。

## 2. LGA-12 引脚

| 脚 | 名称 | I2C 接法 | 说明 |
| --- | --- | --- | --- |
| 1 | AD0 | GND 或 VDD | 地址 LSB；GND=0x12，VDD=0x13 |
| 2 | SDX | SDA | I2C 数据 |
| 3 | VDD | 3.3V | 主电源，就近 100nF |
| 4 | RESV1 | 悬空或 GND | 保留，按手册接 |
| 5 | INT1 | MCU 中断/唤醒 | 可映射抬腕、双击等 |
| 6 | INT2 | MCU 中断/唤醒 | 可映射另一路中断 |
| 7 | NC | 悬空 | 不接 |
| 8 | GNDIO | GND | IO 地 |
| 9 | GND | GND | 内部地 |
| 10 | SENB | VDDIO 或悬空 | I2C 模式选 I2C；SPI 模式作 CSB |
| 11 | RESV2 | 悬空 | 保留 |
| 12 | SCX | SCL | I2C 时钟 |

要点：

- **AD0=GND → 0x12；AD0=VDD → 0x13**。需求文档写 0x12/0x13，做板前按实物确认。
- SENB 在 I2C 模式接 VDDIO 或悬空，不要按 SPI 的 CSB 用法接。
- RESV1/RESV2 不要接电源，按手册悬空或接地。
- LGA-12 的 1 脚方向必须按丝印和贴片图；贴反轴向全错。
- I2C 与 OPT3001（0x44）共总线，4.7kΩ 上拉到 3.3V，400kHz 不冲突。

## 3. 电源模式与功耗

| 模式 | 电流 | 说明 |
| --- | --- | --- |
| Standby | 0.5µA | 上电默认，I2C 可访问，但不做运动检测 |
| 低功耗 Active | 5–44µA | 随 ODR 变化，最低约 5µA |
| 低噪声 Active | 38–149µA | 高 ODR/低噪声模式 |

- 模式由 `0x11<7>` MODE_BIT 控制：1=Active，0=Standby。
- 软复位：`0x36 = 0xB6`。
- 启动时间约 2ms，唤醒约 1ms。

**与当前需求文档的冲突：**

需求文档写 QMA6100P“待机 0.5µA、工作 2µA”。数据手册给的低功耗工作电流是 **5–44µA**，不是 2µA。

如果 QMA 要检测抬腕/双击，它必须处于 Active，最低约 5µA；再加 MCU Stop 1.5µA、墨水屏 1µA、OPT3001 0.1µA、100µF 电容漏电，整机 5µA 休眠目标基本不可能成立。

需要拍板：

- 放宽整机休眠指标到 10µA 量级；或
- QMA 大部分时间进 Standby，另找唤醒源；但 Standby 下不能检测抬腕/双击；或
- 降低抬腕/双击的检测频率，确认 QMA 最低功耗档是否满足。

## 4. 内置中断与算法

| 中断 | 作用 | 关键寄存器 |
| --- | --- | --- |
| STEP_INT | 计步 | 0x16<3>/<6> 使能，0x0A<3>/<6> 状态，0x19/0x1B 映射 |
| TAP_INT | 单击/双击/三击/四击 | 0x16<7/5/4/0> 使能，0x0A/0x0B 状态，0x2B/0x1E 阈值 |
| RAISE_INT | 抬手/放手唤醒 | 0x16<1> RAISE_EN、0x16<2> HD_EN，0x22–0x26 阈值 |
| ANY_MOT | 任意运动 | 0x18 使能，0x2E 阈值，0x2C 持续时间 |
| SIG_MOT | 显著运动 | 0x2F 等配置 |
| NO_MOT | 静止检测 | 0x18/0x2C/0x2D |
| FIFO | 64 帧缓存 | 0x3F、0x31，0x17/0x1A/0x1C 中断 |
| DRDY | 新数据 | 0x0A/0x0B 状态 |

INT1/INT2 的引脚行为由 `0x20` 配置：

- `INT1_OD/INT2_OD`：开漏或推挽
- `INT1_LVL/INT2_LVL`：高有效或低有效

测光表建议：

- **INT1 → 抬腕唤醒**（RAISE_INT）
- **INT2 → 双击**（D_TAP_INT）
- 自动转屏不用专用中断，读 X/Y/Z 算横竖屏即可。

注意：RAISE_INT 是“抬手/放手”算法，不完全等于腕部抬起；阈值 0x22–0x26 需要打样后实测调。TAP_INT 的单击/双击阈值在 0x2B/0x1E，也要实测调。

## 5. 关键寄存器

| 地址 | 名称 | 说明 |
| --- | --- | --- |
| 0x00 | CHIP ID | 默认 0x90，上电先读确认 |
| 0x01–0x06 | X/Y/Z 数据 | 14 位补码，低/高字节 |
| 0x0A/0x0B | 中断状态 | 读后清 |
| 0x0F | FSR | 0x01=2g，0x02=4g，0x04=8g，0x08=16g，0x0F=32g |
| 0x11 | PM | bit7=1 Active，bit7=0 Standby |
| 0x16 | 中断使能 | STEP/TAP/RAISE/HD 等 |
| 0x19/0x1A | INT1 映射 | 内部中断映射到 INT1 |
| 0x1B/0x1C | INT2 映射 | 内部中断映射到 INT2 |
| 0x20 | INT_PIN_CFG | 推挽/开漏、高/低有效 |
| 0x22–0x26 | RAISE 阈值 | 抬手/放手灵敏度与周期 |
| 0x2B/0x1E | TAP 阈值 | 冲击/静默阈值 |
| 0x2E/0x2C | ANY_MOT 阈值/时间 | 任意运动 |
| 0x36 | S_RESET | 写 0xB6 软复位 |
| 0x3F/0x31 | FIFO 配置/水位 | 64 帧 FIFO |

## 6. 上电与配置流程

1. VDD 上电，等 2ms 以上。
2. 读 0x00，确认 0x90。
3. 写 0x36=0xB6 软复位，等复位完成。
4. 写 0x0F 设量程：抬腕/双击建议 ±4g（0x02）；要抗冲击可 ±8g（0x04）。
5. 写 0x11<7>=1 进 Active。
6. 配 0x16 中断使能、0x19/0x1B 映射、0x20 引脚极性。
7. 读 0x0A/0x0B 清状态，读 0x01–0x06 取数据。

数据格式：14 位补码；±2g 时 244µg/LSB，±4g 时 488µg/LSB。换算时按所选量程做符号扩展。

## 7. 与测光表需求的对应

| 需求 | QMA6100P 对应 | 结论 |
| --- | --- | --- |
| 抬腕唤醒 | RAISE_INT 内置 | 可用，阈值需实测 |
| 双击唤醒 | TAP_INT 的 D_TAP | 可用，阈值需实测 |
| 自动转屏 | 读三轴数据算 roll/pitch | 可用，无专用中断 |
| I2C 共总线 | 0x12/0x13，OPT3001 0x44 | 不冲突 |
| 待机 0.5µA | Standby 0.5µA | 但 Standby 不能检测运动 |
| 工作 2µA | 手册最低约 5µA | 需求值不成立，需要改 |
| 5µA 整机休眠 | QMA 常开至少 5µA | 和 5µA 目标冲突 |

## 8. 布局与调试

- LGA-12 2×2mm，1 脚方向必须按丝印和贴片图；贴反轴向全错。
- 尽量靠近板中心，远离墨水屏升压 L1/Q1/D1–D3 和 24V 开关。
- VDD 就近 100nF；GNDIO/GND 都接地。
- I2C 上拉 4.7kΩ 到 3.3V；400kHz 下确认总线电容。
- INT1/INT2 走线短，接 MCU 的 Stop 唤醒脚。
- AD0 接 GND 或 VDD 定地址，不要悬空。
- SENB 在 I2C 模式接 VDDIO 或悬空，不要按 SPI CSB 接。
- 首件用读 CHIP ID 0x90 和静止时 Z 轴约 1g 验证轴向与焊接。

## 9. 检查清单

- [ ] AD0 地址确认：0x12 或 0x13。
- [ ] SENB 按 I2C 模式接 VDDIO/悬空。
- [ ] 1 脚方向与丝印一致。
- [ ] VDD 100nF 去耦，GNDIO/GND 接地。
- [ ] I2C 上拉 4.7kΩ，和 OPT3001 共总线。
- [ ] INT1/INT2 映射到抬腕/双击，接 MCU 唤醒脚。
- [ ] 0x00 读回 0x90。
- [ ] 0x0F 量程、0x11 Active 配置正确。
- [ ] 抬腕/双击阈值实测可调。
- [ ] 5µA 休眠指标与 QMA 常开功耗重新核对。
