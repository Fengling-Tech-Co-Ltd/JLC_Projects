## 3. 关键说明

### 3.1 I2C

- SCL=PB3，SDA=PB4，AF6。
- 与 OPT3001（0x44）、QMA6100P（当前 AD0=3V3 → 0x13）共总线。
- 4.7kΩ 上拉到 3.3V；400kHz 下确认总线电容。
- I2C_INT=PA4 保留给 OPT3001 或共享中断；QMA 的 INT1/INT2 用 PC1/PB7，接 EXTI 唤醒。
- QMA6100P 的 VDD 就近 100nF 去耦；SENB 接 3V3 固定 I2C 模式。

### 3.2 SPI 与墨水屏

- SPI 只使用 SCK=PB0、MOSI=PA7、CS=PA6。
- 墨水屏是只写 SPI，**MISO 不接**；原 MISO 脚 PA1 改作 ENC_KEY。
- 墨水屏 DC=PA5、RES=PA0、BUSY=PB2。
- CS 建议用 GPIO 软件控制，避免硬件 NSS 按字节翻转。
- BUSY 接 PB2 的 EXTI；DC/RES 是普通输出。
- 如果以后还要 SPI MISO，当前没有空闲脚，需要重新分配。

### 3.3 编码器

- A 相 PB5，接 EXTI；B 相 PB1，普通 GPIO。
- 按压 ENC_KEY=PA1，低有效，接 Stop 唤醒脚。
- A/B 各 10kΩ 上拉到 3.3V；按压 10kΩ 上拉，按下接 GND。
- 预留 10kΩ+100nF 消抖焊盘，默认不贴，优先固件消抖。
- A/B 顺序决定方向，反了交换 A/B 或固件取反。

### 3.4 串口与调试

- TXD=PA3，AF1。
- USART_RX 未分配；当前只有 TXD。需要 RX 时必须重新分配（PA2/PA4/PA7/PB5 之一）。
- SWDIO=PB6，SWCLK=PA2；NRST=PC0。
- 做板时保留 SWD 排针，方便烧录和调试。

### 3.5 QMA 中断与空闲脚

- 不使用外部 32.768kHz 晶振，系统时钟用内部 RC；PC1/PB7 释放为 QMA 中断。
- QMA INT1=PC1（pin5），INT2=PB7（pin6），都配置为 GPIO 输入 / EXTI。
- I2C_INT=PA4 保留给 OPT3001 或共享中断。
- 18 个 IO 已全部用满，没有空闲脚。
- QMA 的 INT1/INT2 如果配置为开漏，需要 10kΩ 上拉到 3.3V；推挽则不用。

## 4. 上电与 bring-up 检查

- [ ] TSSOP20 pin1 方向与丝印一致。
- [ ] VCC pin9 3.3V，100nF+1µF 去耦；VSS pin7 接地。
- [ ] SWDIO=PB6、SWCLK=PA2、NRST=PC0 可连接。
- [ ] I2C 扫描能看到 OPT3001 0x44、QMA 0x13（当前 AD0=3V3）。
- [ ] 墨水屏 SCK=PB0、MOSI=PA7、CS=PA6、DC=PA5、RES=PA0、BUSY=PB2 波形正常。
- [ ] 编码器 A=PB5、B=PB1 正交解码正确；ENC_KEY=PA1 按下为低。
- [ ] TXD=PA3 有调试输出。
- [ ] QMA INT1=PC1、INT2=PB7 能触发 EXTI；确认内部 RC 时钟配置。
- [ ] 未用功能/测试点按需求保留。
