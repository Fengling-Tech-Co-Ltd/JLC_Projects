# 胶片相机测光板

胶片相机外挂测光表的**验证板**：双墨水屏显示、环境光强测量、姿态检测、旋转编码器操作，主控 PY32L020F15P7。

本目录是设计资料合集，不含固件工程。

## 1. 系统构成

| 模块 | 器件 | 接口 |
|---|---|---|
| 主控 | PY32L020F15P7（TSSOP20） | — |
| 光强传感 | OPT3001-Q1 | I2C 0x44，量程 0.01~83k lux |
| 姿态 | QMA6100P | I2C 0x13，INT1/INT2 推挽，支持抬腕/双击/转屏 |
| 主屏 | GDEY0154D67（1.54"，200×200）或 GDEM0122T61（1.22"，192×176） | FPC1，24Pin，SSD1681 |
| 副屏 | GDEM0097T61（0.97"，184×88） | FPC2，18Pin + 2 定位，SSD1680 |
| 操作 | 旋转编码器 E8H6（带按压） | 10k 上拉，A/B/按键 |

两块墨水屏**任何时刻只插一块**，SPI 用 6 个跳线选择，每个 3Pin 排针只装一个跳线帽。

## 4. 已知架构限制（先看，别当 bug）

| 项 | 结论 |
|---|---|
| 1.54 / 1.22 全屏 UI | L020 只有 3KB SRAM，跑不了整屏缓冲，必须条带渲染；或换 F030/F003 的 8KB |
| 0.97 屏 | 可以在 L020 上跑 |
| 整机休眠 | 5 µA 目标与 QMA 常开手势冲突，实际按 10~15 µA，CR2032 约 2 年 |
| RTC 精度 | 无 LSE，24h ±2s 达不到 |
| 刷新跌落 | <0.3 V 需 100 µF 缓冲，当前 57 µF，需实测 |
| 升压 | 1.54/1.22 的 15µH/3Ω 经计算可行，2.4 V 下需实测 VGH/VGL |
| 上电时序 | R10、R11 已去掉；固件要处理 BUSY 悬空、OPT INT 开漏、I2C 休眠时保持高电平 |

## 5. 器件手册要点

- **两块屏不能互换转接模块**：CV0097 / DESPI-C02 / DESPI-K154 的 24Pin 脚名与原始 GDEY/GDEM 屏不同，只能当参考；FPC1 按原始 24Pin 接
- **0.97 四色屏（GDEM0097F51）** 与 FPC2 不匹配，不要直接插
- **F030 与 L020 同为 TSSOP20 但引脚定义不同**，不能直接替换
- 1.54/1.22 的 VPP 电容：成品模块保留，原始屏手册写 Keep Open，两种做法都见过
- 编码器两种型号（YTS23 / E8H6）脚位和每转定位数不同，换料前对规格书
