## 与当前设计的对应

| 设计对象 | 手册 | 备注 |
| --- | --- | --- |
| MCU | PY32L020F15P7（全局库）；F030 备选 | F030 与 L020 同为 TSSOP20，但引脚定义不同，不能直接替换 |
| 1.54 屏 | GDEY0154D67 + SSD1681 | FPC1 24Pin，原始屏 pin4 NC、pin5 VSH2 |
| 1.22 屏 | GDEM0122T61 | 与 1.54 共用 FPC1，24Pin 定义一致 |
| 0.97 屏 | GDEM0097T61 | FPC2 是 18 信号 + 2 定位脚，不要插四色 F51 |
| 光强 | OPT3001-Q1 | 0x44，4.7k 上拉 |
| 姿态 | QMA6100P | 0x13，INT1/INT2 推挽 |
| 编码器 | E8H6 | 10k 上拉，A/B/按键 |

## 使用提醒

- 两块屏任何时刻只插一块，SPI 用 6 个跳线选择，每个 3Pin 排针只装一个跳线帽。
- 1.54/1.22 的 VPP 电容按成品模块保留；原始屏手册写 Keep Open，两种做法都见过。
- 0.97 四色 F51 的引脚和 FPC2 不匹配，不要直接插。
- 转接模块的 24Pin 脚名和原始屏不同，不能混插；做兼容前先对 pin4/5/21/23。
- 方案文档在 `..\方案文档`，固件注意事项见 `..\方案文档\固件开发注意事项.md`。
