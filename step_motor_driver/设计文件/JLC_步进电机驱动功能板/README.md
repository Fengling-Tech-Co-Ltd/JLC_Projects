# JLC_step_motor_driver

双轴步进电机驱动功能板，PY32F030K28T6 主控配两片 DRV8825PWPR，24V 单电源输入，立创EDA 专业版工程。

## 功能

- 双轴独立驱动，每轴相电流 1.0 ~ 3.5A 可调，推荐工作点 1.5A
- 主控 PY32F030K28T6，ARM Cortex-M0+，LQFP32，48MHz，64KB Flash / 8KB SRAM
- 驱动芯片 DRV8825PWPR × 2，ETSSOP-28 带散热焊盘
- 电机接口 JST PH 2.0mm 4 芯卧插 × 2，额定 2A
- 输入 24V DC，2A 以上；PTC 自恢复保险、双向 TVS、肖特基防反接
- 3.3V 由 LM317MDT 线性稳压，带预负载，供主控与驱动器逻辑上拉
- 限流由 MCU 的 20kHz PWM 加 RC 滤波设定，两轴各自独立
- 细分模式全步（200 步/转），MODE0/1/2 硬件下拉固定
- 调试口 2×4 2.0mm 排针，含 SWD 与 USART1

## 关键计算

| 项目 | 值 | 依据 |
|---|---|---|
| 相电流设定 | `I_CHOP = VREF / (5 × Rcs)` | Rcs = 200mΩ，故 VREF 每 1V 对应 1A |
| 推荐相电流 | 1.5 A | VREF = 1.5V，位于 1.0 ~ 3.5V 推荐区间中段 |
| VREF 滤波截止频率 | 15.9 Hz | `1 / (2π × 10K × 1µF)` |
| VREF 建立时间 | 约 30 ms | 软件启动必须等待，否则电机可能猛冲 |
| 3V3 输出 | 3.28 V | `1.25 × (1 + 390 / 240)`，R19 = 240Ω，R20 = 390Ω |
| 3V3 侧负载 | 约 10 mA | LM317 耗散约 0.22W，热余量充足 |
| 母线储能 | 151 µF | 入口 57µF + 每片驱动本地 47µF |
| 驱动芯片耗散 | 约 1.8 W | `2 × I² × Rds(on)`，I = 1.5A，Rds(on) ≈ 0.32Ω |
| 母线电流 | 约 0.78 A | 两轴各 1.5A 相电流折算到 24V，PTC 额定 2A 有余量 |

定时器分工：TIM3 出两路 VREF（同频 20kHz，占空比各自独立）；TIM16 出 STEP_1，TIM1 出 STEP_2，两个独立定时器保证两轴转速互不影响。同一外设的通道共用 ARR，所以 STEP 与 VREF 不能挂在同一个定时器上。

### PWM 配置

| 信号 | MCU 引脚 | 定时器/通道 | 用途 |
| --- | --- | --- | --- |
| VREF_1 | PB5 | TIM3_CH2 | 轴 1 电流设定 |
| VREF_2 | PB4 | TIM3_CH1 | 轴 2 电流设定 |
| STEP_1 | PB8 | TIM16_CH1 | 轴 1 步进脉冲 |
| STEP_2 | PA8 | TIM1_CH1 | 轴 2 步进脉冲 |

**VREF PWM（TIM3）**

- 定时器时钟 48MHz，预分频 0，ARR=2399，频率 20kHz。
- `VREF = 3.3 × CCR / 2400`，`I_CHOP = VREF / (5 × 0.2Ω) = VREF`（A）。
- 1.5A 对应 VREF=1.5V，CCR≈1091；分辨率 1.375mV/count，约 1.375mA/count。
- RC 滤波 10kΩ/1µF，截止约 15.9Hz；设完 VREF 等 30ms 再发 STEP。

**STEP PWM（TIM16 / TIM1）**

- 50% 占空比，`f_STEP = 48MHz / (ARR + 1)`，`CCR = (ARR + 1) / 2`。
- DRV8825 STEP 高/低最小 1.9µs，f_STEP 不超过 250kHz；250kHz 时 ARR=191、CCR=96。
- 当前 MODE0/1/2 硬件固定全步，200 步/转，`RPM = 0.3 × f_STEP`。
- 1kHz → 300rpm，5kHz → 1500rpm，10kHz → 3000rpm。
- f_STEP 低于约 732Hz 时 ARR 超过 65535，需要加预分频。
- DIR/ENBL 要在 STEP 上升沿前至少 650ns 稳定，固件建议留 1µs 以上。
