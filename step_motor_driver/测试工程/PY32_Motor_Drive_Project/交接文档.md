## 1. 硬件与引脚

| 功能 | MCU 引脚 | 复用/方向 | 说明 |
|---|---|---|---|
| STEP_1 | PB8 | TIM16_CH1（AF2） | 轴 1 步进脉冲 |
| STEP_2 | PA8 | TIM1_CH1（AF2） | 轴 2 步进脉冲 |
| VREF_1 | PB4 | TIM3_CH1（AF1） | 轴 1 相电流设定，20kHz PWM |
| VREF_2 | PB5 | TIM3_CH2（AF1） | 轴 2 相电流设定，20kHz PWM |
| DIR_1 | PA0 | GPIO 输出 | 高 = 正转 |
| DIR_2 | PA5 | GPIO 输出 | 高 = 正转 |
| NENBL_1 | PF3 | GPIO 输出 | 低有效，低 = 使能 |
| NENBL_2 | PA4 | GPIO 输出 | 低有效，低 = 使能 |
| RESET_1 | PB3 | GPIO 输出 | 高正常，低 = 驱动复位 |
| RESET_2 | PA6 | GPIO 输出 | 高正常，低 = 驱动复位 |
| USART1_TX | PF1 | AF0 | 调试命令口，115200 8N1 |
| USART1_RX | PF0 | AF0 | 调试命令口 |
| SWDIO / SWCLK | PA13 / PA14 | — | 烧录调试 |

复用编号已对照 PY32F030 数据手册 Rev1.3 的复用表逐项核对（PF1 的 USART1_TX 在 AF0、PF0 的 USART1_RX 在 AF0）。

MODE0/1/2 硬件下拉固定为**全步**，200 步/转；DECAY 悬空 = 混合衰减；nFAULT 只上拉、未接 MCU。

## 2. 时钟

**HSI 24MHz × PLL2 = 48MHz**，AHB / APB1 均不分频。

不能用 HSE：PF0/PF1 已作 USART1_TX/RX，这两脚同时是 OSC_IN/OSC_OUT，板上没有外部晶振。
空白工程原本开 HSE，**必须**改，否则 `HAL_RCC_OscConfig` 失败直接进 `APP_ErrorHandler`。

## 3. 关键参数

| 项 | 值 | 依据 |
|---|---|---|
| VREF PWM | TIM3，PSC=0，ARR=2399 → 20kHz | 48MHz / 2400 |
| 相电流换算 | `CCR = mA × 2400 / 3300`（四舍五入） | VREF = 3.3 × CCR/2400，I = VREF/(5×0.2Ω) |
| 参考点 | 1.2A → CCR 873；1.5A → CCR 1091 | |
| 默认电流 | **1.2A** | 1.5A 时结温约 121°C，先按 1.2A |
| 电流范围 | 1000 ~ 3500 mA（软件钳位） | 板子设计区间 |
| VREF 建立 | 上电后等 30ms 再放 nRESET | RC = 10k/1µF，截止 15.9Hz |
| STEP 频率 | `f = 48MHz / ((PSC+1)(ARR+1))`，50% 占空比 | |
| STEP 上限 | 250kHz（DRV8825 要求高低各 ≥1.9µs） | |
| 预分频 | 低于约 732Hz 才自动加 PSC | ARR 超 65535 |
| 转速换算 | 全步 200 步/转，`RPM = 0.3 × f_STEP` | |
| DIR 建立 | 改向后至少等 5µs 再发 STEP | 手册要求 ≥650ns |

## 4. 上电顺序（不能调换）

1. nENBL 拉高（禁用）、nRESET 拉低（驱动复位）
2. 写入两轴 VREF
3. 等 30ms（VREF 的 RC 建立）
4. 放开 nRESET，等 ≥10µs
5. nENBL 拉低使能
6. 之后才允许发 STEP

顺序错了会在 VREF 未建立时给电机冲电流。

## 5. 代码结构

全部扁平放在 `User/`，不另建 Src/Inc：

| 文件 | 职责 |
|---|---|
| `main.c` | 初始化、上电顺序、自检动作、错误处理 |
| `bsp_clock.c/h` | HSI 24M → PLL ×2 → 48MHz |
| `bsp_motor_io.c/h` | DIR / nENBL / nRESET 三组 GPIO |
| `bsp_vref.c/h` | TIM3 双通道 20kHz，`vref_set_current_ma()` |
| `bsp_step.c/h` | TIM16/TIM1 脉冲输出，自动选 PSC，STEP 周期回调 |
| `app_motion.c/h` | 按步数走 / 连续转，计步中断里自动停机 |
| `app_console.c/h` | USART1 文本命令行（见下） |
| `py32f0xx_it.c` | USART1 / TIM16 / TIM1 三个中断入口 |

依赖单向：`bsp_*` → `app_motion` → `main`，业务层不碰寄存器。

## 6. 两个自检宏（main.c 顶部）

```c
#define PF1_TOGGLE_TEST   0   // 置 1：PF1 当 GPIO 每秒翻转，用于查板级走线
#define MOTOR_DEMO_ENABLE 1   // 置 1：开机自动跑电机动作
```

**当前设置：`MOTOR_DEMO_ENABLE = 1`**，上电后 1 秒开始，循环执行：

```
轴1 正转 1 圈 → 停 0.8s → 轴1 反转 1 圈 → 停 0.8s
→ 轴2 正转 1 圈 → 停 0.8s → 轴2 反转 1 圈 → 停 0.8s → 循环
```

速度/步数改这三个宏：`DEMO_STEP_HZ`（默认 400 ≈ 120rpm）、`DEMO_STEPS`（默认 200 = 1 圈）、`DEMO_WAIT_MS`。

要改回命令控制时，把 `MOTOR_DEMO_ENABLE` 改成 0。

