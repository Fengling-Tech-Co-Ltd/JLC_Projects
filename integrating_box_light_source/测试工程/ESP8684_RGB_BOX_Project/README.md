# 积分盒四色光源板 固件（交接文档）

> 目标芯片：ESP8684（ESP32-C2），ESP-IDF v5.3.3
> 依据：`D:\桌面\工作内容\私活\光模块功能板\AI_固件交接文档.md`
> 状态更新：2026-11-23（编译已通过；实物已烧录验证到四路点灯）

本文件是固件工程的总览。逐项实现、踩坑与最新调整见同目录 `_固件交接说明.md`，细节以它为准。

## 1. 这个工程是什么

胶片翻拍用积分盒的四色 LED 光源固件。四路 R/G/B/IR 独立恒流驱动，一路 DAC 控制亮度，一路 ADC 读光强反馈，带慢速闭环与标定存储。

不做业务编排，只负责“把光调到目标值”和“把状态报出来”。

## 2. 硬件与接线

| 项 | 值 |
|---|---|
| I2C | **GPIO0 = SDA，GPIO1 = SCL，100 kHz** |
| 上拉 | 主板 4.7k，软件只开内部弱上拉 |
| MCP4728 | 0x60，VREF=VDD(3.3V)，LDAC# 接地 |
| ADS1110 | 0x48，连续 15SPS，增益 1，LSB 62.5 µV |
| AL8862 恒流 | `I = 0.1 V / R_SET`，本板 **R_SET = 0.30 Ω → 满量程 333.3 mA** |
| CTRL 区间 | 0.4~2.5 V 对应 10%~100%（33.3~333.3 mA），低于 0.3 V 关断，高于 2.6 V 钳位 |
| 跨阻 | 47 kΩ，1 µA 光电流 ≈ 47 mV |

通道与硬件对应：

| 逻辑通道 | MCP4728 | 驱动 IC | 焊桥跳线 | 限流电阻 | 灯珠 |
|---|---|---|---|---|---|
| R 红 | CH1 | U4 | **JP1** | R1（0.30Ω） | LED_R1~R4 |
| G 绿 | CH2 | U5 | **JP2** | R2（0.30Ω） | LED_G1~G4 |
| B 蓝 | CH3 | U6 | **JP3** | R3（0.30Ω） | LED_B1~B4 |
| IR 红外 | CH4 | U7 | **JP4** | R4（0.30Ω） | LED_IR1~IR4 |

每路 4 颗 3535 灯珠串联，只能整路一起亮。**JP1~JP4 必须短接**，否则 DAC 输出到 AL8862 CTRL 是断开的，表现为“I2C 写成功、CTRL 一直 0V、灯不亮”。

### 2.1 为什么是 100 kHz 而不是 400 kHz

实测 400 kHz 下：ADS1110 读操作大量 NACK，MCP4728 出现“写成功但某个通道不变”（例：写 CH1 的 3102，CH1 仍是上一档 0.514 V）。降到 100 kHz 后同一块板零 NACK、DAC 输出正常。排线较长或总线电容大时还会更差，不要往上调。

## 4. 上电流程

1. NVS 初始化
2. I2C 总线（GPIO0/1，100 kHz）
3. 扫总线，打印 `dac(0x60)=? adc(0x48)=?`
4. `light_init()`：General Call Wake-Up → 四路写 0 关断 → 配 ADS1110（失败重试 5 次）→ 等 100 ms → 读暗底 → 从 NVS 载标定
5. **上电点灯**（见 §5）
6. 起控制台
7. 主循环：100 ms 拍（`light_monitor_tick()` 刷监视），每 10 拍跑一次 `light_task()` 闭环

顺序不能改：`light_init` 里的关断与暗底采样必须在点灯之前。

## 5. 上电默认点灯

由 `light_cfg.h` 的 `LIGHT_BOOT_R/G/B/IR_MA` 决定，当前（2026-11-23）：

| 通道 | 上电电流 | 说明 |
|---|---|---|
| R / G / B / IR | **各 50 mA（15%）** | 满量程 333.3 mA，code=642，CTRL≈0.52 V |

说明：

- 上电四路同时点亮；需要单独关闭某一路，把对应 `LIGHT_BOOT_*_MA` 改成 0。
- **10%（33.3 mA）这一档尚未在当前 0.30 Ω 板上验证**；旧 0.50 Ω 板上 20 mA 档 AL8862 起不来，所以默认取 15%。
- **红外不可见（850 nm）**，不能靠眼睛判断亮没亮，要用 `meas ir` 或手机摄像头。

改亮度：改 `light_cfg.h` 重新编译，或运行时用控制台 `set r|g|b|ir <mA>`。

## 6. 控制台命令（UART0 **74880**）

> 不是 115200。`CONFIG_ESP_CONSOLE_UART_BAUDRATE` 在 esp32c2 + 26 MHz XTAL 下由 Kconfig 固定为 74880，手改 sdkconfig 会被覆盖。

| 命令 | 作用 |
|---|---|
| `scan` | 扫 I2C 总线 |
| `off` | 四路全关 |
| `set <ch> <mA>` | 按 LED 电流设置，ch 可写 0-3 或 r/g/b/ir |
| `code <ch> <n>` | 直接给 DAC 码（0~3102），用于绕过换算量 CTRL 电压 |
| `meas [ch]` | 测光电流；不带参数四路轮测 |
| `tgt <ch> <uA>` | 设闭环目标光电流 |
| `loop on\|off` | 闭环开关 |
| `mode a\|b` | a = 分时（默认，能分通道闭环），b = 同时 |
| `cal` / `calsave` | 四路 50% 标定 / 写入 NVS |
| `status` | 打印 code、CTRL 电压、电流、目标、增益、故障标志 |
| `vin` | 强制单次转换，打印 ADS1110 VIN+ 的原始码/配置字/电压 |
| `mon on\|off` | 100 ms 连续打印 `[VIN]` 电压 |

通道打印已带硬件编号：`R(CH1)`、`G(CH2)`、`B(CH3)`、`IR(CH4)`。

## 7. 闭环与标定

- **分时模式（默认）**：`light_measure_ua()` 临时关掉其余三路，测完恢复。会改变输出，**曝光期间不要调用**。
- **同时模式**：单颗宽带 BPW34S 分不清通道，只能做总光强前馈 + 慢速修正。
- 闭环周期 1 s，每拍处理一路，四路 4 秒一圈；`LIGHT_DEFAULT_KP = 2.0`（code/µA），实测再调。
- 标定：四路各 50% 电流测一次，得 `µA/code`，`calsave` 写入 NVS 命名空间 `light_cal`（带 magic + CRC）。注意：当前 `s_gain` 只存不用，闭环仍是固定 Kp。

## 8. 关键常量与换算

| 项 | 值 | 位置 |
|---|---|---|
| DAC 满码 | 3102（2.5 V @ 3.3 V） | `light_cfg.h` |
| 满量程电流 | **333.3 mA**（R_SET=0.30Ω） | `light_cfg.h` |
| 采样次数 | 8 | `ADS_AVG_N` |
| 饱和门限 | 32000 码 | `ADS1110_SAT_RAW` |
| 标定命名空间 | `light_cal` | `light_cfg.h` |

代码与电流换算：

```c
uint16_t code = (uint16_t)(v / 3.3f * 4096.0f + 0.5f);   // v ∈ [0.4, 2.5]
```

**MCP4728 多写命令字节必须是 `0x40 | (ch << 1)`**，通道号在 bit2:1。原始交接文档写的是 `0x40 | ch`，那是错的：照抄会让 G 重复写 A、B 错位、IR 重复写 B，四路里只有红路正确。这条已核对手册 5.6.3 并修正。

`drv_mcp4728` 里还有 General Call Wake-Up（0x00/0x09）：器件可能带着 EEPROM 的 PD 位上电，此时普通写虽然 ACK 但输出被关断，Wake-Up 清掉 PD 位后才有输出。

## 9. 编译与烧录

```bat
build.cmd            :: idf.py build，内部用 D:\esp\v5.3.3
flash.cmd COM36      :: 不传参数默认 COM6
```

用 VS Code 乐鑫扩展时注意：

1. 用**工程根目录**打开，不要用上级目录
2. 扩展选的 IDF 必须是 `D:\esp\v5.3.3\esp-idf`，与 `build.cmd` 同一套，否则 `sdkconfig` 会被另一版重写
3. `idf.buildPath` 要指向本工程（`${workspaceFolder}/build`），不能指向别的工程
4. `main/CMakeLists.txt` 的组件名是 **`console`**，不是 `esp_console`（后者只是头文件名）
5. `build.cmd` 末尾有 `pause`，命令行调用要加 `< nul`

## 11. 已知问题与注意事项

1. **I2C 只能 100 kHz**（见 §2.1），不要恢复 400 kHz。
2. **低亮度档**：当前默认 15%（50 mA）；再低先确认 AL8862 能稳定起振。
3. **红外不可见**，判断靠 `meas`/`vin` 数值或手机摄像头，不靠眼睛。
4. **`hello_world_main.c` 不参与编译**，别删也别把它的 `app_main` 恢复进编译列表，会重复定义。
5. **上电顺序**：关断与暗底采样必须在点灯之前，否则暗底会被当前点亮状态污染。
6. **NVS 标定**：换板或换灯珠后要重新 `cal` + `calsave`。
7. **分时测量会关灯**：`light_measure_ua()` 在分时模式下会切断其他三路，曝光期间调用会毁掉画面。
8. **JP1~JP4 必须短接**，否则对应通道的 DAC 输出到不了 AL8862。
9. **ADS1110 VIN+ 当前异常**：软件读到的输入约 -3 mV 且不随光照变化，先修硬件再谈 `meas` 与闭环。
