# 积分盒四色光源板 固件（交接文档）

> 目标芯片：ESP8684（ESP32-C2），ESP-IDF v5.3.3
> 依据：`D:\桌面\工作内容\私活\光模块功能板\AI_固件交接文档.md`
> 状态更新：2026-11-20（代码最后修改 11-17，编译与烧录已通过）

本文件是当前版本；同目录的 `_固件交接说明.md` 是最初搭骨架时写的，内容已被本文件覆盖，以本文件为准。

## 1. 这个工程是什么

胶片翻拍用积分盒的四色 LED 光源固件。四路 R/G/B/IR 独立恒流驱动，一路 DAC 控制亮度，一路 ADC 读光强反馈，带慢速闭环与标定存储。

不做业务编排，只负责"把光调到目标值"和"把状态报出来"。

## 2. 硬件与接线

| 项 | 值 |
|---|---|
| I2C | **GPIO0 = SDA，GPIO1 = SCL，100 kHz** |
| 上拉 | 主板 4.7k，软件只开内部弱上拉 |
| MCP4728 | 0x60，VREF=VDD(3.3V)，LDAC# 接地 |
| ADS1110 | 0x48，连续 15SPS，增益 1，LSB 62.5 µV |
| AL8862 恒流 | `I = 0.1 V / R_SET`，本板 **R_SET = 0.50 Ω → 满量程 200 mA** |
| CTRL 区间 | 0.4~2.5 V 对应 10%~100%，低于 0.3 V 关断，高于 2.6 V 钳位 |
| 跨阻 | 47 kΩ，1 µA 光电流 ≈ 47 mV |

通道映射：CH1=R、CH2=G、CH3=B、CH4=IR。每路 4 颗 3535 灯珠串联，只能整路一起亮。

### 2.1 为什么是 100 kHz 而不是 400 kHz

实测 400 kHz 下：ADS1110 读操作大量 NACK，MCP4728 出现"写成功但某个通道不变"。降到 100 kHz 后稳定。排线较长或总线电容大时还会更差，不要往上调。

## 4. 上电流程

1. NVS 初始化
2. I2C 总线（GPIO0/1，100 kHz）
3. 扫总线，打印 `dac(0x60)=? adc(0x48)=?`
4. `light_init()`：General Call Wake-Up → 四路写 0 关断 → 配 ADS1110 → 等 100 ms → 读暗底 → 从 NVS 载标定
5. **上电点灯**（见 §5）
6. 起控制台
7. 主循环：100 ms 拍（`light_monitor_tick()` 刷监视），每 10 拍跑一次 `light_task()` 闭环

顺序不能改：`light_init` 里的关断与暗底采样必须在点灯之前。

## 5. 上电默认点灯

由 `light_cfg.h` 的 `LIGHT_BOOT_R/G/B/IR_MA` 决定，当前：

| 通道 | 上电电流 | 说明 |
|---|---|---|
| R / G / B | 0（关闭） | |
| IR | **50 mA（25%）** | 满量程 200 mA |

两个实测结论：

- **10%（20 mA）这一档灯点不亮**，AL8862 在最小档起不来，所以默认取 25%
- **红外不可见**，不能靠眼睛判断亮没亮，要看 `meas ir` 的光电流是否明显高于暗底

改亮度：改 `light_cfg.h` 重新编译，或运行时用控制台 `set ir 50`。

## 6. 控制台命令（UART0 115200）

| 命令 | 作用 |
|---|---|
| `scan` | 扫 I2C 总线 |
| `off` | 四路全关 |
| `set <ch> <mA>` | 按 LED 电流设置，ch 可写 0-3 或 r/g/b/ir |
| `code <ch> <n>` | 直接给 DAC 码（0~3102），用于绕过换算量 CTRL 电压 |
| `meas [ch]` | 测光电流；不带参数四路轮测 |
| `tgt <ch> <uA>` | 设闭环目标光电流 |
| `loop on\|off` | 闭环开关 |
| `mode a\|b` | a = 分时（默认，能分通道闭环），b = 同时 |
| `cal` / `calsave` | 四路 50% 标定 / 写入 NVS |
| `status` | 打印 code、CTRL 电压、电流、目标、增益、故障标志 |
| `vin` | 直接读 ADS1110 VIN+ 原始电压（不扣暗底），诊断光强板用 |
| `mon on\|off` | 100 ms 连续打印 `[VIN]` 电压 |

## 7. 闭环与标定

- **分时模式（默认）**：`light_measure_ua()` 临时关掉其余三路，测完恢复。会改变输出，**曝光期间不要调用**。
- **同时模式**：单颗宽带 BPW34S 分不清通道，只能做总光强前馈 + 慢速修正。
- 闭环周期 1 s，每拍处理一路，四路 4 秒一圈；`LIGHT_DEFAULT_KP = 2.0`（code/µA），实测再调。
- 标定：四路各 50% 电流测一次，得 `µA/code`，`calsave` 写入 NVS 命名空间 `light_cal`（带 magic + CRC）。

## 8. 关键常量与换算

| 项 | 值 | 位置 |
|---|---|---|
| DAC 满码 | 3102（2.5 V @ 3.3 V） | `light_cfg.h` |
| 满量程电流 | 200 mA | `light_cfg.h`，随 R_SET 变 |
| 采样次数 | 8 | `ADS_AVG_N` |
| 饱和门限 | 32000 码 | `ADS1110_SAT_RAW` |
| 标定命名空间 | `light_cal` | `light_cfg.h` |

代码与电流换算：

```c
uint16_t code = (uint16_t)(v / 3.3f * 4096.0f + 0.5f);   // v ∈ [0.4, 2.5]
```

**MCP4728 多写命令字节必须是 `0x40 | (ch << 1)`**，通道号在 bit2:1。原始交接文档写的是 `0x40 | ch`，那是错的：照抄会让 G 重复写 A、B 错位、IR 重复写 B，四路里只有红路正确。这条已核对手册 5.6.3 并修正。

`drv_mcp4728` 里还有 General Call Wake-Up（0x00/0x09）：器件可能带着 EEPROM 的 PD 位上电，此时普通写虽然 ACK 但输出被关断，Wake-Up 清掉 PD 位后才有输出。

## 11. 已知问题与注意事项

1. **I2C 只能 100 kHz**（见 §2.1），不要恢复 400 kHz。
2. **10% 档点不亮**，最低可用档约 25%。
3. **红外不可见**，判断靠 `meas`/`vin` 数值，不靠眼睛。
4. **`hello_world_main.c` 不参与编译**，别删也别把它的 `app_main` 恢复进编译列表，会重复定义。
5. **上电顺序**：关断与暗底采样必须在点灯之前，否则暗底会被当前点亮状态污染。
6. **NVS 标定**：换板或换灯珠后要重新 `cal` + `calsave`，否则闭环按旧增益走。
7. **分时测量会关灯**：`light_measure_ua()` 在分时模式下会切断其他三路，曝光期间调用会毁掉画面。
